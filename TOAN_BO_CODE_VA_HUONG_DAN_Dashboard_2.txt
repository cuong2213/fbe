####################################################################################################
# 1. SƠ ĐỒ HỆ THỐNG
####################################################################################################

1.1 Các sheet
  MAP_VEHICLE : form nhập liệu. Chọn Model, quét VIN, chọn Paint Color, Defect Type, Qty, Inspector; click ô lưới trên hình xe
                để chọn vị trí lỗi; SAVE ghi vào DATABASE. Có panel "XEM DỮ LIỆU DATABASE TRÊN GRID" (heat trên lưới).
  MASTER      : danh mục: tblModels, tblDefectTypes, tblShifts, tblGridZones, tblSettings, tblColors (+ cột trợ giúp V:W).
  DATABASE    : tblDefects = toàn bộ bản ghi lỗi (1 ô lưới được chọn = 1 dòng).
  SUMMARY     : tổng hợp nhanh (tblSummary), cập nhật bằng RefreshSummary sau mỗi SAVE.
  Dashboard   : báo cáo gồm bộ lọc, KPI, MAPPING hình xe + Grid (đẩy lên đầu, rộng bằng report), các biểu đồ và cuối cùng là bảng DEFECT DETAIL (vị trí tùy chiều cao Mapping). Nút REFRESH / RESET FILTERS / EXPORT TO PDF.
  Config      : cài đặt Dashboard (tblDashSettings) + màu từng Defect Type (tblDefectColors).
  DASH_CALC   : sheet ẩn chứa dữ liệu trung gian cho biểu đồ (không sửa tay).

1.2 Bảng dữ liệu chính
  tblDefects (DATABASE!A1): DefectID, BatchID, DateTime, ShiftDate, Model, VIN, View, X, Y, CellID, GridID, DefectType, Qty,
                            Shift, Inspector, Description, Status, PaintColor(*mới, nằm cuối bảng)
      X = cột lưới, Y = hàng lưới, CellID dạng Excel (ví dụ C7 = cột 3, hàng 7), GridID dạng R7C3.
  tblModels (MASTER!A1)       : Model, Rows, Cols, ImageShapeName, Active   (Rows x Cols = kích thước lưới của Model)
  tblDefectTypes (MASTER!G1)  : DefectType, Active
  tblShifts (MASTER!J1)       : Shift, StartTime, EndTime, Active
  tblGridZones (MASTER!O1)    : Model, View, XFrom, XTo, YFrom, YTo   (vùng LH/RH/FRONT/REAR/TOP trên lưới)
  tblSettings (MASTER!Y1)     : ImageWidth, ImageHeight (kích thước hình Master chung cho mọi Model)
  tblColors (MASTER!AC1)      : PaintColor, Hex   (*mới: danh sách màu sơn + mã màu #RRGGBB dùng tô biểu đồ)
  tblDashSettings (Config!A3) : TopN, StablePct, DetailMaxRows, DefaultDays, CountMode, AutoRefreshOnActivate
  tblDefectColors (Config!F3) : DefectType, Color  (tô màu ô cột Color để đổi màu loại lỗi)

1.3 Luồng dữ liệu
  [MAP_VEHICLE] --SAVE--> tblDefects --(bấm REFRESH / đổi bộ lọc)--> RunDashboard:
      ReadFilters -> LoadAndAggregate (gộp số liệu vào các từ điển r*) -> các Update* vẽ KPI/biểu đồ/Mapping.
  Thứ tự trong RunDashboard: kiểm tra sheet & bố cục -> ReadFilters -> LoadAndAggregate -> màu Defect -> dropdown -> KPI -> MAPPING (tính chiều cao)
      -> UpdateCharts (xu hướng, theo ca) -> Tròn Defect Type -> Tròn Model -> Tỉ lệ lỗi/xe -> Màu sơn -> ArrangeBelowMapping (đặt biểu đồ + Defect Detail dưới Mapping) -> tiêu đề.

1.4 Bố cục Dashboard (hàng) - VỊ TRÍ ĐỘNG: tính lại mỗi lần Refresh theo chiều cao của Mapping (SetLayoutRows ở Module2)
  1-3    Tiêu đề + dòng trạng thái (A3)    |  4-5  Bộ lọc: A5 From, C5 To, E5 Model, G5 Shift, I5 Defect, K5 Cell, M5 TopN
  8-11   4 KPI (Total Defects, Affected Vehicles, Defects per Vehicle, Top Defect Type)
  13     Thanh tiêu đề "VEHICLE DEFECT MAPPING" (ROW_HM_TITLE)   |  14 ghi chú (ROW_HM_NOTE)
  15..gRowHmLast  MAPPING: rộng bằng cả report (A:N), MỖI HÀNG NGANG 2 HÌNH, tối đa 4 Model (= 2 hàng hình).
                  Chiều cao tùy số Model: <= 2 Model khoảng hàng 15-34; 3-4 Model khoảng hàng 15-52. Hình KHÔNG bị thu nhỏ.
  Ngay dưới Mapping (cách LAYOUT_GAP = 1 hàng), mỗi dải cao CH_ROWS = 15 hàng, nối tiếp nhau:
       dải 1: Xu hướng theo ngày & ca (A:G)  |  Xu hướng theo Defect Type (H:N)
       dải 2: BIỂU ĐỒ TRÒN tỉ lệ lỗi theo Defect Type (A:G)  |  Defect by Shift (H:N)
       dải 3: BIỂU ĐỒ TRÒN số lỗi theo Model/loại xe (A:G)  |  Tỉ lệ lỗi theo màu sơn (H:N)
       dải 4: Biểu đồ tỉ lệ lỗi / xe theo ngày (A:N)
  Dưới cùng: DEFECT DETAIL = thanh tiêu đề, hàng tiêu đề cột, rồi dữ liệu (tối đa Config > DetailMaxRows dòng, mới nhất trước).
       Vị trí của Defect Detail KHÔNG cố định: nằm ngay dưới dải 4 nên dịch theo chiều cao của Mapping.
  Các bảng Defect Summary / Ma trận Defect Type x Model / Top 3 đã bỏ; chỉ giữ Defect Detail.

####################################################################################################
# 2. CÀI ĐẶT: DÁN CODE VÀO FILE EXCEL CỦA CÔNG TY
####################################################################################################

2.1 Chuẩn bị
  a) Đóng Excel. Sao lưu file .xlsm ra một bản copy (để quay lại nếu cần).
  b) Mở file, Enable Content / Enable Macros, bấm Alt+F11 để mở VBE. Bật Project Explorer (Ctrl+R).
  c) NẾU file công ty đã có code riêng: copy code cũ của từng module ra Notepad để đối chiếu trước khi xóa.

2.2 Đối chiếu module (tên module có thể khác, hãy nhận diện theo tên Sub bên trong)
  Khối trong file này | Tìm trong file công ty module/sheet chứa...  | Loại
  ThisWorkbook        | ThisWorkbook (Microsoft Excel Objects)        | Workbook
  Sheet1              | Sheet có tên hiển thị MAP_VEHICLE            | Sheet (class)
  Module1             | Sub SaveDefectRecords / SetupWorkbook          | Module chuẩn
  Module2             | Function DashSheet / NewDict / DefectColor     | Module chuẩn
  Module3             | Function LoadAndAggregate / ReadFilters        | Module chuẩn
  Module4             | Sub UpdateCharts / UpdateKPI                    | Module chuẩn
  Module5             | Sub InitializeDashboard / RunDashboard          | Module chuẩn
  Sheet8              | Sheet có tên hiển thị Dashboard                | Sheet (class)
  (Trong Project Explorer, sheet hiện dạng "Sheet8 (Dashboard)": số Sheetn trong ngoặc là tên hiển thị của sheet.)

2.3 Cách dán (làm cho TỪNG khối)
  - Mở module/sheet tương ứng (double-click). Ctrl+A -> Delete (xóa hết code cũ) -> dán khối code ở mục 5.
  - Chỉ dán phần NẰM GIỮA hai dòng "BẮT ĐẦU CODE" và "HẾT CODE". Dòng đầu tiên là "Option Explicit" (hoặc comment).
  - KHÔNG dán dòng "Attribute VB_Name = ..." (đã được lược bỏ sẵn). Tên module có thể giữ nguyên hoặc đổi tại cửa sổ
    Properties (F4), ví dụ Module1 -> modVehicleMapping; code không phụ thuộc tên module.
  - Nếu công ty chưa có module nào trong số trên: Insert > Module, dán code vào. Với ThisWorkbook / sheet: dán vào đúng đối tượng.
  - Dán XONG HẾT 8 khối rồi mới Debug > Compile VBAProject (các module gọi lẫn nhau nên compile từng khối sẽ báo thiếu).

2.4 Khởi chạy lần đầu
  - Lưu file (.xlsm), đóng rồi mở lại, Enable Macros. Workbook_Open gọi InitWorkbook -> tự tạo bảng màu (MASTER!tblColors),
    cột PaintColor trong tblDefects, ô Paint Color ở MAP_VEHICLE!B8, dropdown, bảo vệ sheet.
  - Nếu workbook CHƯA có các sheet/bảng (file mới hoàn toàn): chạy Sub SetupWorkbook (F5) một lần để dựng MAP_VEHICLE, MASTER,
    DATABASE, SUMMARY; rồi chạy InitializeDashboard để dựng Dashboard/Config/DASH_CALC (hỏi xác nhận, không xóa dữ liệu).
  - Dashboard: bố cục đã đổi (bỏ bảng, Mapping lên đầu) nên PHẢI chạy Sub InitializeDashboard (F5) MỘT LẦN để dựng lại khung.
    Sau đó bấm REFRESH DASHBOARD để vẽ biểu đồ và Mapping.

# 3. CHỨC NĂNG TỪNG MODULE + CÁCH TÙY CHỈNH
####################################################################################################


----------------------------------------------------------------------------------------------------
3.1 ThisWorkbook  (khối "ThisWorkbook")
----------------------------------------------------------------------------------------------------
Nhiệm vụ: khi mở file chạy InitWorkbook (khởi tạo giao diện MAP_VEHICLE, nạp dropdown, tải Model đang chọn, bảo vệ sheet).
Tùy chỉnh: có thể thêm các lệnh khởi động khác ngay sau InitWorkbook (ví dụ tự RefreshDashboard khi mở).

----------------------------------------------------------------------------------------------------
3.2 Sheet MAP_VEHICLE  (khối "Sheet1")
----------------------------------------------------------------------------------------------------
Nhiệm vụ: các sự kiện của sheet nhập liệu.
  Worksheet_Change         : đổi Model (B2) -> LoadVehicleModel (xóa lưới cũ, ẩn ảnh cũ, hiện ảnh mới, tạo lưới mới);
                             nhập VIN (B3) -> NormalizeVIN (bỏ CR/LF thừa, giữ dạng Text). KHÔNG tự Save.
  Worksheet_SelectionChange: cập nhật Shift/ShiftDate/DateTime; sau khi quét VIN, scanner gửi Enter/Tab làm con trỏ nhảy
                             -> đưa con trỏ về D4 (Inspector nếu trống) hoặc D5 (Defect Type).
Tùy chỉnh: ô nhập cố định theo bố cục: B2 Model, B3 VIN, B8 Paint Color, D4 Inspector, D5 Defect Type, D6 Qty, D7 Description.
  Đổi vị trí ô nào thì phải đổi đồng bộ ở: Sheet1 (khối này), ValidateInput, SaveDefectRecords, ResetInputFields,
  ApplyValidation, ApplyProtection, BuildMapSheet (Module1).

----------------------------------------------------------------------------------------------------
3.3 Module nhập liệu (Module1 ~ modVehicleMapping)
----------------------------------------------------------------------------------------------------
Nhiệm vụ: toàn bộ logic của sheet MAP_VEHICLE + khởi tạo workbook. Các nhóm chức năng:

  [Hằng số/khai báo đầu module]
    SH_MAP/SH_MASTER/SH_DB/SH_SUM : tên sheet.      TBL_*: tên bảng (TBL_COLORS = tblColors mới).
    ANCHOR_IMG ("F2")          : ô góc trên-trái đặt hình Master + lưới.
    IMG_MAX_WIDTH (1100)       : chỉ THU NHỎ hình nếu rộng hơn (point); 0 = giữ nguyên.
    IMG_PLACEHOLDER_WIDTH (900): độ rộng hình tạm khi chưa có hình thật.
    GRID_PREFIX ("CELL_") / IMG_PREFIX ("IMG_") : tiền tố tên shape ô lưới / hình Master (CELL_R{hàng}_C{cột}).
    COLOR_SELECTED             : màu ô lưới đang chọn (xanh lá).      MAX_LIST_ROWS (60): số dòng tối đa danh sách dropdown.

  [Tiện ích] GetSheet, GetTable, colIdx, TableHasData, FindShape, FindImageShape, ColumnLetter(n -> A,B,..AA), NewID(prefix),
             IsActiveValue (Yes/True/1...), GetGridCoordinates (đọc hàng/cột từ tên shape).
  [Ca làm việc] GetShiftInfo(thời điểm, ca, ShiftDate): xác định ca theo MASTER!tblShifts (ca đêm qua nửa đêm -> ShiftDate là
             ngày bắt đầu ca). UpdateShiftDisplay: hiển thị Shift (B7), Shift Date (D2), Date Time (D3).
  [Hình + lưới] LoadVehicleModel(model): đổi Model; HideAllImages; DeleteGridShapes; CreateVehicleGrid (dựng Rows x Cols
             shape theo tblModels, chia đều trên hình); SetCellHighlight; CanReuseGrid (không dựng lại nếu cùng kích thước).
  [Chọn ô lỗi] GridCell_Click -> ToggleGridCell(r,c): chọn/bỏ chọn; ClearSelection; EnsureSelection; UpdateSelCount (B4).
  [Nhập liệu] NormalizeVIN; ValidateInput (kiểm tra Model, VIN, Paint Color, ô đã chọn, Defect Type Active, Qty nguyên >= 1,
             Inspector, lưới đúng Model); SaveDefectRecords (ghi mỗi ô chọn thành 1 dòng tblDefects cùng BatchID, ShiftDate, Shift,
             PaintColor, rồi RefreshSummary, xóa lựa chọn, reset ô nhập); GetViewForCell (View theo tblGridZones);
             ResetInputFields(clearInspector); BtnSave/BtnClear/BtnReset (gán cho nút).
  [Xem dữ liệu trên lưới] ShowDatabaseOnGrid(silent): tô lưới theo số lỗi từ tblDefects theo bộ lọc B21:B26 (From, To, VIN,
             Shift, Defect Type, Show value = Qty/Records); HideDatabaseOnGrid; ClearHeatDisplay; BtnShowData/BtnHideData.
  [Lịch B21/B22] ShowCalendar, DrawCalendar, CalPick, Cal_DayClick/Today/Clear/Close/Nav, CloseCalendar/ForceCloseCalendar:
             lịch chọn ngày bằng Shape cho 2 ô From/To của panel xem dữ liệu.
  [SUMMARY] RefreshSummary: cập nhật tblSummary (gọi sau mỗi SAVE).
  [Khởi tạo] EnsureNamedLists (ActiveModels/ActiveDefects), ApplyValidation (dropdown + kiểm tra nhập), ApplyProtection/ProtectMap
             (khóa sheet, chỉ mở ô nhập; UserInterfaceOnly), InitWorkbook (Workbook_Open), SetupWorkbook (dựng sheet/bảng/nút lần đầu,
             KHÔNG xóa dữ liệu), EnsureSheets, EnsureTable, BuildMasterSheet/BuildDatabaseSheet/BuildSummarySheet/BuildMapSheet,
             CreatePlaceholderImages.
  [MỚI - Paint Color] EnsureColorSupport(ws): tạo MASTER!tblColors (AC1), thêm cột PaintColor cuối tblDefects, dựng ô Paint Color
             ở hàng 8 và dịch các nút xuống (RepositionPanelButtons); EnsureDefectColorColumn.

Tùy chỉnh thường dùng:
  - Thêm Model: MASTER > tblModels thêm dòng (Model, Rows, Cols, ImageShapeName, Active=Yes) và đặt hình tên IMG_xxx lên MAP_VEHICLE.
  - Đổi kích thước/độ phân giải lưới: sửa Rows/Cols của Model (Mapping trên Dashboard tự theo). Đổi kích thước hình chung: MASTER > tblSettings.
  - Thêm loại lỗi / ca / vùng View / màu sơn: MASTER > tblDefectTypes / tblShifts / tblGridZones / tblColors.
  - Thêm màu sơn: thêm dòng vào tblColors (PaintColor, Hex dạng #RRGGBB). Màu Hex quyết định màu thanh trên biểu đồ theo màu sơn.
  - Muốn Paint Color KHÔNG bắt buộc: trong ValidateInput xóa khối "2b. Paint Color".
  - Muốn đổi màu ô lưới được chọn: sửa COLOR_SELECTED. Muốn lưới/hình lớn hơn: sửa IMG_MAX_WIDTH.
  - Muốn đổi mặc định Qty: sửa dòng ws.Range("D6").Value = 1 trong ResetInputFields và BuildMapSheet.

----------------------------------------------------------------------------------------------------
3.4 Module tiện ích Dashboard (Module2 ~ modDashCommon)
----------------------------------------------------------------------------------------------------
Nhiệm vụ: hằng số bố cục + hàm dùng chung. KHÔNG chứa logic báo cáo.
  Hằng số: SH_DASH/SH_CFG/SH_CALC (tên sheet); TBL_DSET/TBL_DCOL (bảng Config); F_FROM..F_TOPN (ô bộ lọc A5,C5,E5,G5,I5,K5,M5);
           KPI1_VAL..KPI4_SUB (ô KPI);
           BỐ CỤC (hàng): ROW_HM_TITLE (13), ROW_HM_NOTE (14), ROW_HM_FIRST (15) = đầu vùng Mapping; HM_MIN_ROWS (6) / HM_DEFAULT_ROWS (38) = chiều cao
           tối thiểu / mặc định của Mapping; CH_ROWS (15) = số hàng mỗi dải biểu đồ; LAYOUT_GAP (1) = số hàng trống giữa các khối;
           DASH_CLEAR_LAST (1500) = hàng cuối được xóa và vẽ lại mỗi lần Refresh.
           Biến vị trí ĐỘNG (do SetLayoutRows tính): gRowHmLast, gRowChTrend, gRowChPie, gRowChPie2, gRowChRate, gRowLast, gRowDtTitle, gRowDtHdr, gRowDtFirst.
  Hàm: DashSheetExists/DashSheet/DashTryTable/DashTable/DashColIndex (tìm sheet, bảng, cột - báo lỗi rõ ràng);
       DashEnsureTable (tạo bảng nếu chưa có); FastOn/FastOff/ForceRestoreApp (tắt/bật ScreenUpdating, Events, Calculation,
       lồng nhau an toàn); NewDict/AddTo/AddNested (từ điển cộng dồn); SortDictKeys (sắp theo giá trị giảm dần); Top3;
       CfgValue(tên, mặc định) (đọc Config > tblDashSettings); PaletteColor/SyncDefectColors/DefectColor (màu từng Defect Type từ Config);
       DashBand(ws, cột đầu, cột cuối, hàng đầu) = vùng ô của một dải biểu đồ (cao CH_ROWS hàng);
       SetLayoutRows(hàng cuối Mapping) = tính vị trí các dải biểu đồ và Defect Detail nằm dưới Mapping.
Tùy chỉnh:
  - Đổi ô bộ lọc/KPI: sửa hằng số F_* / KPI*; rồi sửa BuildDashboardLayout (Module5) cho khớp và chạy lại InitializeDashboard.
  - Vị trí các khối là ĐỘNG: muốn đổi thứ tự (ví dụ đặt Defect Detail trước biểu đồ) sửa SetLayoutRows; đổi chiều cao dải biểu đồ / khoảng cách: CH_ROWS, LAYOUT_GAP.
  - Mapping rộng bằng report: độ rộng lấy theo cột A:N (dòng availW trong UpdateHeatmap, Module4); muốn hẹp lại thì sửa dòng đó.
  - Đổi tên sheet: sửa SH_* (và đổi tên sheet thật trong Excel).

----------------------------------------------------------------------------------------------------
3.5 Module dữ liệu Dashboard (Module3 ~ modDashData)
----------------------------------------------------------------------------------------------------
Nhiệm vụ: đọc bộ lọc và quét tblDefects MỘT LẦN, gộp kết quả vào các biến Public để các Update* dùng.
  ReadFilters(msg)  : đọc F_FROM.. F_TOPN thành fFrom,fTo (serial ngày), fModel,fShift,fDef,fCell,fTopN; tính kỳ trước (pFrom,pTo).
  ParseRow          : kiểm tra 1 dòng hợp lệ (có Model/VIN/Defect/Cell, Qty đúng, xác định được ngày & ca); trả q (Qty hoặc 1).
  PassBase          : áp bộ lọc Model/Shift/Defect/Cell.   InitCols: lấy chỉ số cột (PaintColor là cột tùy chọn).
  LoadAndAggregate  : vòng lặp chính; điền rTotal, rVin (tập VIN = số xe), rDefQty/rDefVin (theo Defect Type), rDateShift,
                      rDateDef, rShiftQty/rShiftVin, rModelQty (số lỗi theo Model - dùng cho biểu đồ tròn theo Model), rModelCell,
                      rDefCell, rCellQty, rMatrix, rDefPrev (kỳ trước), rDateQty/rDateVin (theo ngày), rColorQty/rColorVin (theo màu sơn),
                      rHeat (Model|Defect|hàng,cột -> số lỗi; nguồn của Mapping).
  MergeMasterList   : thêm mục Active từ MASTER vào danh sách dropdown. ResetResults: khởi tạo lại các biến kết quả.
Tùy chỉnh:
  - Đếm theo Qty hay số bản ghi: Config > CountMode (Qty / Records).
  - Muốn thêm một thống kê mới: khai báo Public r... As Object; Set r... = NewDict() trong ResetResults; thêm
    AddTo / AddNested trong khối "If sd >= fFrom And sd <= fTo Then" của LoadAndAggregate; rồi dùng nó trong module hiển thị.
  - Đổi tiêu chí hợp lệ của dòng dữ liệu: sửa ParseRow.   - Ngày lọc là ShiftDate (ngày sản xuất); nếu trống thì suy ra từ DateTime.

Option Explicit
Private Sub Worksheet_Change(ByVal Target As Range)
    On Error GoTo EH
    'Doi Model (B2): xoa grid cu, an anh cu, hien anh moi, tao grid moi
    If Not Intersect(Target, Me.Range("B2")) Is Nothing Then
        LoadVehicleModel CStr(Me.Range("B2").Value)
    End If
    'VIN (B3): bo CR/LF thua, giu nguyen dang Text. KHONG Save.
    If Not Intersect(Target, Me.Range("B3")) Is Nothing Then
        NormalizeVIN
    End If
    Exit Sub
EH:
    Application.EnableEvents = True
    MsgBox "Worksheet_Change loi: " & Err.Description, vbExclamation
End Sub
Private Sub Worksheet_SelectionChange(ByVal Target As Range)
    On Error Resume Next
    'Cap nhat Shift / ShiftDate / DateTime (khong dung Timer)
    UpdateShiftDisplay
    'Sau khi quet VIN, scanner gui Enter/Tab lam con tro nhay sang B4 hoac C3.
    'Dua con tro ve o nhap lieu ke tiep (Inspector neu dang trong, nguoc lai Defect Type).
    If gVinJustEntered Then
        gVinJustEntered = False
        If Target.Cells.Count = 1 Then
            If Target.Address(False, False) = "B4" Or Target.Address(False, False) = "C3" Then
                If Len(Trim$(CStr(Me.Range("D4").Value))) = 0 Then
                    Me.Range("D4").Select
                Else
                    Me.Range("D5").Select
                End If
            End If
        End If
    End If
End Sub

Private Function FindImageShape(ByVal ws As Worksheet, ByVal imgName As String) As Shape
    'Uu tien hinh that (Picture...). Hinh tam (AutoShape) chi dung khi chua co hinh that; neu co hinh that thi xoa hinh tam trung ten.
    Dim s As Shape, real As Shape, temp As Shape, i As Long
    Set s = FindShape(ws, imgName)                  'duong nhanh: tra theo ten
    If Not s Is Nothing Then
        If s.Type <> msoAutoShape Then Set FindImageShape = s: Exit Function
    End If
    Set s = Nothing
    For Each s In ws.Shapes                         'duong cham: co hinh tam / trung ten
        If StrComp(s.Name, imgName, vbTextCompare) = 0 Then
            If s.Type = msoAutoShape Then
                If temp Is Nothing Then Set temp = s
            Else
                If real Is Nothing Then Set real = s
            End If
        End If
    Next s
    If Not real Is Nothing Then
        For i = ws.Shapes.Count To 1 Step -1
            If StrComp(ws.Shapes(i).Name, imgName, vbTextCompare) = 0 Then
                If ws.Shapes(i).Type = msoAutoShape Then ws.Shapes(i).Delete
            End If
        Next i
        Set FindImageShape = real
    Else
        Set FindImageShape = temp
    End If
End Function

Public Function ColumnLetter(ByVal colNum As Long) As String
    Dim n As Long, s As String
    n = colNum
    Do While n > 0
        s = Chr$(65 + ((n - 1) Mod 26)) & s
        n = (n - 1) \ 26
    Loop
    ColumnLetter = s
End Function

Public Function GetGridCoordinates(ByVal shapeName As String, ByRef r As Long, ByRef c As Long) As Boolean
    'Ten shape: CELL_R{row}_C{col}
    Dim p() As String
    If Left$(shapeName, 6) <> "CELL_R" Then Exit Function
    p = Split(Mid$(shapeName, 7), "_C")
    If UBound(p) <> 1 Then Exit Function
    If Not IsNumeric(p(0)) Or Not IsNumeric(p(1)) Then Exit Function
    r = CLng(p(0))
    c = CLng(p(1))
    GetGridCoordinates = True
End Function

Private Function GetModelInfo(ByVal modelName As String, ByRef nRows As Long, ByRef nCols As Long, _
                              ByRef imgName As String) As Boolean
    'Tra ve True neu Model ton tai trong tblModels va Active = Yes
    Dim lo As ListObject, dat As Variant, i As Long
    Dim cM As Long, cR As Long, cC As Long, cI As Long, cA As Long
    Set lo = GetTable(SH_MASTER, TBL_MODELS)
    If Not TableHasData(lo) Then Exit Function
    cM = colIdx(lo, "Model"): cR = colIdx(lo, "Rows"): cC = colIdx(lo, "Cols")
    cI = colIdx(lo, "ImageShapeName"): cA = colIdx(lo, "Active")
    dat = lo.DataBodyRange.Value2
    For i = 1 To UBound(dat, 1)
        If StrComp(Trim$(CStr(dat(i, cM))), Trim$(modelName), vbTextCompare) = 0 Then
            If IsActiveValue(dat(i, cA)) And IsNum(dat(i, cR)) And IsNum(dat(i, cC)) Then
                nRows = CLng(dat(i, cR))
                nCols = CLng(dat(i, cC))
                imgName = Trim$(CStr(dat(i, cI)))
                If nRows >= 1 And nCols >= 1 Then GetModelInfo = True
            End If
            Exit Function
        End If
    Next i
End Function

Public Sub GetShiftInfo(ByVal inputTime As Date, ByRef shiftName As String, ByRef productionDate As Date)
    Dim h As Long
    h = Hour(inputTime)
    If h >= 6 And h < 14 Then
        shiftName = "S1": productionDate = DateValue(inputTime)
    ElseIf h >= 14 And h < 22 Then
        shiftName = "S2": productionDate = DateValue(inputTime)
    ElseIf h >= 22 Then
        shiftName = "S3": productionDate = DateValue(inputTime)
    Else                                   '00:00 - 05:59
        shiftName = "S3": productionDate = DateValue(inputTime) - 1
    End If
End Sub

Private Function GetImageSize(ByRef w As Double, ByRef h As Double) As Boolean
    'Doc kich thuoc hinh Master CHUNG cho moi Model tu MASTER > tblSettings (ImageWidth / ImageHeight, don vi point)
    'Tra ve False neu khong co bang hoac gia tri khong hop le -> dung cach cu (giu ti le, toi da IMG_MAX_WIDTH)
    Dim lo As ListObject, dat As Variant, i As Long, cs As Long, cV As Long, k As String
    On Error GoTo Fail
    w = 0: h = 0
    Set lo = GetTable(SH_MASTER, TBL_SETTINGS)
    If Not TableHasData(lo) Then Exit Function
    cs = colIdx(lo, "Setting"): cV = colIdx(lo, "Value")
    dat = lo.DataBodyRange.Value2
    For i = 1 To UBound(dat, 1)
        k = LCase$(Trim$(CStr(dat(i, cs))))
        If k = "imagewidth" And IsNum(dat(i, cV)) Then w = CDbl(dat(i, cV))
        If k = "imageheight" And IsNum(dat(i, cV)) Then h = CDbl(dat(i, cV))
    Next i
    GetImageSize = (w >= 50 And h >= 50)
    Exit Function
Fail:
    GetImageSize = False
End Function

Private Function CanReuseGrid(ByVal ws As Worksheet, ByVal nR As Long, ByVal nC As Long, ByVal img As Shape) As Boolean
    'Grid dang co tren sheet khop hoan toan (so hang/cot, vi tri, kich thuoc o) voi hinh -> khong can tao lai
    Dim a As Shape, z As Shape, tol As Double
    tol = 0.5
    Set a = FindShape(ws, GRID_PREFIX & "R1_C1")
    If a Is Nothing Then Exit Function
    Set z = FindShape(ws, GRID_PREFIX & "R" & nR & "_C" & nC)
    If z Is Nothing Then Exit Function
    If Not FindShape(ws, GRID_PREFIX & "R" & (nR + 1) & "_C1") Is Nothing Then Exit Function
    If Not FindShape(ws, GRID_PREFIX & "R1_C" & (nC + 1)) Is Nothing Then Exit Function
    If Abs(a.Left - img.Left) > tol Or Abs(a.Top - img.Top) > tol Then Exit Function
    If Abs(a.Width - img.Width / nC) > tol Or Abs(a.Height - img.Height / nR) > tol Then Exit Function
    If Abs((z.Left + z.Width) - (img.Left + img.Width)) > tol Then Exit Function
    If Abs((z.Top + z.Height) - (img.Top + img.Height)) > tol Then Exit Function
    CanReuseGrid = True
End Function

Public Function LoadVehicleModel(ByVal modelName As String) As Boolean
    Dim ws As Worksheet, nR As Long, nC As Long, imgName As String, shp As Shape, g As Shape
    Dim prevEv As Boolean, wasProt As Boolean, T0 As Double, usingPlaceholder As Boolean
    Dim reused As Boolean, perfSet As Boolean, prevCalc As Long, prevPB As Boolean
    Dim hasSize As Boolean, imgW As Double, imgH As Double
    On Error GoTo EH
    mStep = "khoi dong"
    prevEv = Application.EnableEvents
    Application.EnableEvents = False
    Application.ScreenUpdating = False
    Set ws = GetSheet(SH_MAP)
    T0 = Timer
    If ws.ProtectContents Then wasProt = True: ws.Unprotect   'bao ve sheet lam cham thao tac shape

    On Error Resume Next                    'tang toc: tat tinh toan va hien thi ngat trang trong luc xu ly
    prevCalc = Application.Calculation
    Application.Calculation = xlCalculationManual
    prevPB = ws.DisplayPageBreaks
    ws.DisplayPageBreaks = False
    perfSet = True
    Err.Clear
    On Error GoTo EH

    If Len(Trim$(modelName)) = 0 Then
        mStep = "xoa Grid (khong chon Model)"
        ResetModelState ws
        GoTo CLEANUP
    End If

    mStep = "doc tblModels"
    If Not GetModelInfo(modelName, nR, nC, imgName) Then
        ResetModelState ws
        MsgBox "Model '" & modelName & "' khong co trong tblModels, khong Active, hoac Rows/Cols khong hop le.", _
               vbExclamation, "Loi Model"
        GoTo CLEANUP
    End If

    mStep = "tim hinh " & imgName
    Set shp = FindImageShape(ws, imgName)
    If shp Is Nothing Then
        ResetModelState ws
        MsgBox "Khong tim thay hinh Master '" & imgName & "' cho Model '" & modelName & "'." & vbCrLf & _
               "Hay chen hinh vao sheet MAP_VEHICLE va dat Name = " & imgName & " (Name Box)." & vbCrLf & _
               "Grid KHONG duoc tao.", vbCritical, "Thieu hinh Master"
        GoTo CLEANUP
    End If

    mStep = "an anh cu"
    HideAllImages

    '4: hien thi anh moi (cac thuoc tinh phu bo qua loi neu loai hinh khong ho tro)
    mStep = "dat kich thuoc/vi tri hinh " & imgName
    hasSize = GetImageSize(imgW, imgH)       'kich thuoc chung cho moi Model (MASTER > tblSettings)
    On Error Resume Next
    If hasSize Then shp.LockAspectRatio = msoFalse Else shp.LockAspectRatio = msoTrue
    Err.Clear
    On Error GoTo EH
    If hasSize Then
        If Abs(shp.Width - imgW) > 0.01 Then shp.Width = imgW
        If Abs(shp.Height - imgH) > 0.01 Then shp.Height = imgH
    ElseIf IMG_MAX_WIDTH > 0 Then
        If shp.Width > IMG_MAX_WIDTH Then shp.Width = IMG_MAX_WIDTH   'Grid chia theo dung kich thuoc hinh
    End If
    shp.Left = ws.Range(ANCHOR_IMG).Left
    shp.Top = ws.Range(ANCHOR_IMG).Top
    On Error Resume Next
    shp.Placement = xlFreeFloating
    Err.Clear
    shp.Visible = msoTrue
    Err.Clear
    shp.ZOrder msoSendToBack
    Err.Clear
    usingPlaceholder = (shp.Type = msoAutoShape)
    Err.Clear
    On Error GoTo EH

    '5: Grid - dung lai neu khop hoan toan, nguoc lai xoa va tao moi
    mStep = "kiem tra Grid hien co"
    reused = CanReuseGrid(ws, nR, nC, shp)
    If reused Then
        mStep = "dung lai Grid (xoa chon / heatmap)"
        ClearSelection
        ClearHeatDisplay
        Application.ScreenUpdating = False
    Else
        mStep = "xoa Grid cu"
        DeleteGridShapes
    End If

    Set gSelectedCells = CreateObject("Scripting.Dictionary")
    Set mHeat = Nothing: mHeatMax = 0: mHeatActive = False
    gModel = "": gRows = 0: gCols = 0
    ws.Range("A29:D29").ClearContents
    ws.Range("B4").Value = 0
    Application.StatusBar = False

    If reused Then
        mStep = "ghi nhan Model cho Grid dung lai"
        Set g = FindShape(ws, GRID_PREFIX & "R1_C1")
        g.AlternativeText = modelName
        mGridRows = nR: mGridCols = nC
    Else
        mStep = "tao Grid"
        CreateVehicleGrid modelName, nR, nC, shp
    End If

    '6: cap nhat Rows/Cols
    mStep = "ghi Rows/Cols"
    gModel = modelName: gRows = nR: gCols = nC
    ws.Range("B5").Value = nR
    ws.Range("B6").Value = nC
    LoadVehicleModel = True
    Application.StatusBar = "Da tai Model " & modelName & " (" & nR & "x" & nC & ") trong " & Format$(Timer - T0, "0.0") & " giay" & _
                            IIf(reused, " - dung lai Grid", "")

CLEANUP:
    On Error Resume Next
    If perfSet Then
        ws.DisplayPageBreaks = prevPB
        Application.Calculation = prevCalc
    End If
    If wasProt Then ProtectMap ws
    On Error GoTo 0
    Application.ScreenUpdating = True
    Application.EnableEvents = prevEv
    If usingPlaceholder Then
        MsgBox "Dang hien thi hinh TAM (o xam) cho Model '" & modelName & "'." & vbCrLf & _
               "Hay chen hinh Master that, dat Name = " & imgName & " (Name Box). Code se tu dung hinh that va bo hinh tam.", _
               vbExclamation, "Chua co hinh Master"
    End If
    Exit Function
EH:
    MsgBox "LoadVehicleModel loi: " & Err.Description & vbCrLf & "Buoc: " & mStep & vbCrLf & "Ma loi: " & Err.Number, vbCritical
    Resume CLEANUP
End Function

Public Sub DeleteGridShapes()
    'Duong nhanh: xoa ca ShapeRange bang 1 lenh. Duong cham (du phong): duyet tung shape.
    Dim ws As Worksheet, i As Long, r As Long, c As Long, k As Long
    Dim nR As Long, nC As Long, nm() As Variant
    Set ws = GetSheet(SH_MAP)

    nR = mGridRows: nC = mGridCols
    If nR < 1 Or nC < 1 Then                     'mat trang thai (vua mo file) -> suy ra tu B5/B6
        nR = CLng(Val(CStr(ws.Range("B5").Value)))
        nC = CLng(Val(CStr(ws.Range("B6").Value)))
    End If

    If nR >= 1 And nC >= 1 Then
        If Not FindShape(ws, GRID_PREFIX & "R" & nR & "_C" & nC) Is Nothing Then
            ReDim nm(0 To nR * nC - 1)
            For r = 1 To nR
                For c = 1 To nC
                    nm(k) = GRID_PREFIX & "R" & r & "_C" & c
                    k = k + 1
                Next c
            Next r
            On Error Resume Next
            ws.Shapes.Range(nm).Delete
            Err.Clear
            On Error GoTo 0
        End If
    End If
    mGridRows = 0: mGridCols = 0

    'Du phong: con sot shape Grid (khong khop kich thuoc) -> duyet tung shape
    If Not FindShape(ws, GRID_PREFIX & "R1_C1") Is Nothing Then
        For i = ws.Shapes.Count To 1 Step -1
            If Left$(ws.Shapes(i).Name, Len(GRID_PREFIX)) = GRID_PREFIX Then ws.Shapes(i).Delete
        Next i
    End If
End Sub

Public Sub CreateVehicleGrid(ByVal modelName As String, ByVal nR As Long, ByVal nC As Long, ByVal img As Shape)
    'Tao o bang AddShape + Name, sau do dinh dang hang loat (nhanh). Neu dinh dang hang loat loi
    'hoac khong an -> tu dong chuyen sang dinh dang tung o (cham hon nhung chac chan).
    Dim ws As Worksheet, r As Long, c As Long, k As Long, s As Shape
    Dim cw As Double, ch As Double, nm() As Variant, okGroup As Boolean
    Set ws = GetSheet(SH_MAP)
    mStep = "xoa Grid cu (trong CreateVehicleGrid)"
    DeleteGridShapes                       'dam bao khong trung shape
    cw = img.Width / nC
    ch = img.Height / nR
    mStep = "tao o Grid"
    ReDim nm(0 To nR * nC - 1)
    For r = 1 To nR
        For c = 1 To nC
            Set s = ws.Shapes.AddShape(msoShapeRectangle, img.Left + (c - 1) * cw, img.Top + (r - 1) * ch, cw, ch)
            nm(k) = GRID_PREFIX & "R" & r & "_C" & c
            s.Name = CStr(nm(k))
            k = k + 1
        Next c
    Next r

    mStep = "dinh dang hang loat"
    okGroup = FormatGridGroup(ws, nm, modelName)
    If okGroup Then
        On Error Resume Next
        okGroup = (ws.Shapes(CStr(nm(0))).Fill.Transparency > 0.9)
        If Err.Number <> 0 Then okGroup = False: Err.Clear
        On Error GoTo 0
    End If

    If Not okGroup Then
        mStep = "dinh dang tung o"
        For k = 0 To UBound(nm)
            Set s = ws.Shapes(CStr(nm(k)))
            s.AlternativeText = modelName
            On Error Resume Next
            s.Placement = xlFreeFloating
            s.Shadow.Visible = msoFalse
            Err.Clear
            On Error GoTo 0
            s.OnAction = "GridCell_Click"
            SetCellHighlight s, False
        Next k
    End If
    mGridRows = nR: mGridCols = nC
End Sub

Private Function FormatGridGroup(ByVal ws As Worksheet, ByRef nm() As Variant, ByVal modelName As String) As Boolean
    Dim sr As ShapeRange
    On Error GoTo Fail
    Set sr = ws.Shapes.Range(nm)
    sr.AlternativeText = modelName          'ghi nho Model cua grid
    sr.Placement = xlFreeFloating
    sr.Shadow.Visible = msoFalse
    sr.OnAction = "GridCell_Click"
    sr.Fill.Visible = msoTrue
    sr.Fill.Solid
    sr.Fill.ForeColor.RGB = RGB(255, 255, 255)   'mac dinh = SetCellHighlight(shp, False)
    sr.Fill.Transparency = 0.97
    sr.Line.ForeColor.RGB = RGB(110, 110, 110)
    sr.Line.Weight = 0.5
    sr.Line.Transparency = 0.6
    FormatGridGroup = True
    Exit Function
Fail:
    FormatGridGroup = False
End Function

Public Sub SetCellHighlight(ByVal shp As Shape, ByVal isOn As Boolean)
    Dim r As Long, c As Long, hasHeat As Boolean
    If Not isOn Then
        If Not mHeat Is Nothing Then
            If GetGridCoordinates(shp.Name, r, c) Then hasHeat = mHeat.Exists(r & "," & c)
        End If
    End If
    With shp
        .Fill.Visible = msoTrue
        .Fill.Solid
        If isOn Then
            .Fill.ForeColor.RGB = COLOR_SELECTED
            .Fill.Transparency = 0.55
            .Line.ForeColor.RGB = RGB(0, 120, 50)
            .Line.Weight = 1.25
            .Line.Transparency = 0.2
        ElseIf hasHeat Then
            SetHeatFill shp, CDbl(mHeat(r & "," & c))
        Else
            .Fill.ForeColor.RGB = RGB(255, 255, 255)
            .Fill.Transparency = 0.97          'gan nhu trong suot nhung van nhan click
            .Line.ForeColor.RGB = RGB(110, 110, 110)
            .Line.Weight = 0.5
            .Line.Transparency = 0.6
        End If
    End With
End Sub

                If GetGridCoordinates(shp.Name, r, c) Then gSelectedCells(r & "," & c) = True
            End If
        End If
    Next shp
End Sub

Public Sub NormalizeVIN()
    'Goi tu Worksheet_Change khi B3 thay doi. KHONG tu dong Save.
    Dim ws As Worksheet, c As Range, v As Variant, s As String, cleaned As String, prevEv As Boolean
    On Error GoTo EH
    prevEv = Application.EnableEvents
    Application.EnableEvents = False
    Set ws = GetSheet(SH_MAP)
    Set c = ws.Range("B3")
    v = c.Value
    If IsEmpty(v) Then
        gVinJustEntered = False
        GoTo CLEANUP
    End If
    If VarType(v) <> vbString Then
        'Gia tri bi doi thanh so -> da mat so 0 dau
        c.NumberFormat = "@"
        c.ClearContents
        gVinJustEntered = False
        MsgBox "VIN bi nhan dang la SO (mat so 0 dau). O B3 da duoc dat lai dinh dang Text. Hay quet/nhap lai VIN.", vbExclamation
        GoTo CLEANUP
    End If
    s = CStr(v)
    cleaned = Replace(Replace(s, vbCr, ""), vbLf, "")
    If cleaned <> s Then c.Value = cleaned
    gVinJustEntered = (Len(cleaned) > 0)
CLEANUP:
    Application.EnableEvents = prevEv
    Exit Sub
EH:
    gVinJustEntered = False
    Resume CLEANUP
End Sub

Public Function ValidateInput(ByRef msg As String) As Boolean
    Dim ws As Worksheet, model As String, nR As Long, nC As Long, img As String
    Dim loD As ListObject, dat As Variant, i As Long, ct As Long, cA As Long
    Dim defect As String, okDef As Boolean, v As Variant, Bad As Boolean

    ValidateInput = False
    Set ws = GetSheet(SH_MAP)

    '1. Model
    model = Trim$(CStr(ws.Range("B2").Value))
    If Len(model) = 0 Then msg = "Chua chon Model (o B2).": Exit Function
    If Not GetModelInfo(model, nR, nC, img) Then
        msg = "Model '" & model & "' khong hop le hoac khong Active trong tblModels.": Exit Function
    End If

    '2. VIN
    If Len(Trim$(CStr(ws.Range("B3").Value))) = 0 Then
        msg = "VIN dang trong (o B3). Hay quet barcode hoac nhap VIN.": Exit Function
    End If

    '2b. Paint Color
    If Len(Trim$(CStr(ws.Range("B8").Value))) = 0 Then
        msg = "Chua chon Paint Color (o B8)."
        Exit Function
    End If

    '3. Cell da chon
    EnsureSelection
    If gSelectedCells.Count = 0 Then msg = "Chua chon o loi nao tren hinh Master.": Exit Function

    '4. Defect Type
    defect = Trim$(CStr(ws.Range("D5").Value))
    If Len(defect) = 0 Then msg = "Chua chon Defect Type (o D5).": Exit Function
    Set loD = GetTable(SH_MASTER, TBL_DEFECTTYPES)
    If TableHasData(loD) Then
        ct = colIdx(loD, "DefectType"): cA = colIdx(loD, "Active")
        dat = loD.DataBodyRange.Value2
        For i = 1 To UBound(dat, 1)
            If StrComp(Trim$(CStr(dat(i, ct))), defect, vbTextCompare) = 0 And IsActiveValue(dat(i, cA)) Then
                okDef = True: Exit For
            End If
        Next i
    End If
    If Not okDef Then msg = "Defect Type '" & defect & "' khong co trong tblDefectTypes hoac khong Active.": Exit Function

    '5. Qty
    v = ws.Range("D6").Value
    If IsError(v) Or IsEmpty(v) Then
        Bad = True
    ElseIf Not IsNumeric(v) Then
        Bad = True
    ElseIf CDbl(v) < 1 Or CDbl(v) <> Int(CDbl(v)) Then
        Bad = True
    End If
    If Bad Then msg = "Qty per Cell (o D6) phai la so nguyen duong.": Exit Function

    '6. Inspector
    If Len(Trim$(CStr(ws.Range("D4").Value))) = 0 Then msg = "Chua nhap Inspector (o D4).": Exit Function

    '7. Grid dung Model
    If StrComp(GetGridModel(ws), model, vbTextCompare) <> 0 Or _
       FindShape(ws, GRID_PREFIX & "R" & nR & "_C" & nC) Is Nothing Then
        msg = "Grid hien tai khong thuoc Model '" & model & "'. Hay chon lai Model o B2.": Exit Function
    End If

    gModel = model: gRows = nR: gCols = nC
    ValidateInput = True
End Function

Public Sub SaveDefectRecords()
    Dim ws As Worksheet, loDB As ListObject, msg As String
    Dim model As String, vin As String, defect As String, inspector As String, desc As String
    Dim qty As Long, saveTime As Date, saveShift As String, saveShiftDate As Date
    Dim batchID As String, n As Long, r As Long, c As Long, i As Long, k As Long
    Dim arr() As Variant, ix(1 To 17) As Long, hdr As Variant
    Dim nOld As Long, tgt As Range, totalQty As Long, sumErr As String, prevEv As Boolean
    Dim viewName As String, paintColor As String, ixColor As Long

    On Error GoTo EH
    Set ws = GetSheet(SH_MAP)
    If Not ValidateInput(msg) Then MsgBox msg, vbExclamation, "Khong the luu": Exit Sub

    prevEv = Application.EnableEvents
    Application.EnableEvents = False
    Application.ScreenUpdating = False

    Set loDB = GetTable(SH_DB, TBL_DEFECTS)
    EnsureDefectColorColumn loDB
    ixColor = colIdx(loDB, "PaintColor")
    hdr = Array("DefectID", "BatchID", "DateTime", "ShiftDate", "Model", "VIN", "View", "X", "Y", _
                "CellID", "GridID", "DefectType", "Qty", "Shift", "Inspector", "Description", "Status")
    For k = 0 To 16
        ix(k + 1) = colIdx(loDB, CStr(hdr(k)))
    Next k

    model = Trim$(CStr(ws.Range("B2").Value))
    vin = CStr(ws.Range("B3").Value)
    defect = Trim$(CStr(ws.Range("D5").Value))
    qty = CLng(ws.Range("D6").Value)
    inspector = Trim$(CStr(ws.Range("D4").Value))
    desc = CStr(ws.Range("D7").Value)
    paintColor = Trim$(CStr(ws.Range("B8").Value))

    'Thoi diem Save: tinh MOT LAN, dung chung cho ca Batch
    saveTime = Now
    GetShiftInfo saveTime, saveShift, saveShiftDate
    batchID = NewID("B")

    n = gSelectedCells.Count
    ReDim arr(1 To n, 1 To loDB.ListColumns.Count)
    i = 0
    For r = 1 To gRows
        For c = 1 To gCols
            If gSelectedCells.Exists(r & "," & c) Then
                i = i + 1
                viewName = GetViewForCell(model, c, r)
                arr(i, ix(1)) = batchID & "-" & Format$(i, "000")
                arr(i, ix(2)) = batchID
                arr(i, ix(3)) = saveTime
                arr(i, ix(4)) = saveShiftDate
                arr(i, ix(5)) = model
                arr(i, ix(6)) = vin
                arr(i, ix(7)) = viewName
                arr(i, ix(8)) = c                       'X = cot
                arr(i, ix(9)) = r                       'Y = hang
                arr(i, ix(10)) = ColumnLetter(c) & r    'CellID dang Excel
                arr(i, ix(11)) = "R" & r & "C" & c      'GridID
                arr(i, ix(12)) = defect
                arr(i, ix(13)) = qty
                arr(i, ix(14)) = saveShift
                arr(i, ix(15)) = inspector
                arr(i, ix(16)) = desc
                arr(i, ix(17)) = "Open"
                arr(i, ixColor) = paintColor
            End If
        Next c
    Next r
    If i <> n Then
        MsgBox "Danh sach o chon khong dong bo voi Grid. Hay bam CLEAR SELECTION va chon lai.", vbExclamation
        GoTo CLEANUP
    End If

    'Ghi vao tblDefects (khong xoa du lieu cu)
    nOld = 0
    If TableHasData(loDB) Then nOld = loDB.DataBodyRange.Rows.Count
    loDB.Resize loDB.Range.Resize(nOld + n + 1)
    Set tgt = loDB.DataBodyRange.Rows(nOld + 1).Resize(n)
    tgt.Columns(ix(3)).NumberFormat = "dd/mm/yyyy hh:mm:ss"
    tgt.Columns(ix(4)).NumberFormat = "dd/mm/yyyy"
    tgt.Columns(ix(6)).NumberFormat = "@"       'VIN luon la Text
    tgt.Columns(ix(10)).NumberFormat = "@"
    tgt.Columns(ix(11)).NumberFormat = "@"
    tgt.Value = arr

    totalQty = n * qty

    On Error Resume Next
    RefreshSummary
    If Err.Number <> 0 Then sumErr = Err.Description: Err.Clear
    On Error GoTo EH

    ClearSelection
    ResetInputFields False
    If mHeatActive Then ShowDatabaseOnGrid True
    UpdateShiftDisplay
    Application.ScreenUpdating = True
    On Error Resume Next
    ws.Range("B3").Select
    On Error GoTo EH

    msg = "LUU THANH CONG" & vbCrLf & vbCrLf & _
          "BatchID: " & batchID & vbCrLf & _
          "So ban ghi: " & n & vbCrLf & _
          "Tong Qty: " & totalQty & vbCrLf & _
          "Ca: " & saveShift & "   ShiftDate: " & Format$(saveShiftDate, "dd/mm/yyyy")
    If Len(sumErr) > 0 Then msg = msg & vbCrLf & vbCrLf & "Luu y: Refresh SUMMARY loi: " & sumErr
    MsgBox msg, vbInformation, "Vehicle Defect Mapping"

CLEANUP:
    Application.ScreenUpdating = True
    Application.EnableEvents = prevEv
    Exit Sub
EH:
    MsgBox "SaveDefectRecords loi: " & Err.Description, vbCritical
    Resume CLEANUP
End Sub

Public Function GetViewForCell(ByVal modelName As String, ByVal x As Long, ByVal y As Long) As String
    'Tra ve LH/RH/FRONT/REAR/TOP theo tblGridZones; khong co vung -> "MASTER"
    Dim lo As ListObject, dat As Variant, i As Long
    Dim cM As Long, cV As Long, cXF As Long, cXT As Long, cYF As Long, cYT As Long
    GetViewForCell = "MASTER"
    On Error GoTo EH
    Set lo = GetTable(SH_MASTER, TBL_ZONES)
    If Not TableHasData(lo) Then Exit Function
    cM = colIdx(lo, "Model"): cV = colIdx(lo, "View")
    cXF = colIdx(lo, "XFrom"): cXT = colIdx(lo, "XTo")
    cYF = colIdx(lo, "YFrom"): cYT = colIdx(lo, "YTo")
    dat = lo.DataBodyRange.Value2
    For i = 1 To UBound(dat, 1)
        If StrComp(Trim$(CStr(dat(i, cM))), modelName, vbTextCompare) = 0 Then
            If IsNum(dat(i, cXF)) And IsNum(dat(i, cXT)) And IsNum(dat(i, cYF)) And IsNum(dat(i, cYT)) Then
                If x >= CDbl(dat(i, cXF)) And x <= CDbl(dat(i, cXT)) And _
                   y >= CDbl(dat(i, cYF)) And y <= CDbl(dat(i, cYT)) Then
                    If Len(Trim$(CStr(dat(i, cV)))) > 0 Then GetViewForCell = UCase$(Trim$(CStr(dat(i, cV))))
                    Exit Function
                End If
            End If
        End If
    Next i
    Exit Function
EH:
    GetViewForCell = "MASTER"
End Function

Private Sub SetHeatFill(ByVal shp As Shape, ByVal v As Double)
    Dim tt As Double
    If mHeatMax > 0 Then tt = v / mHeatMax
    If tt > 1 Then tt = 1
    With shp
        .Fill.Visible = msoTrue
        .Fill.Solid
        .Fill.ForeColor.RGB = RGB(255 - CLng(35 * tt), 235 - CLng(205 * tt), 60 - CLng(30 * tt))   'vang -> do
        .Fill.Transparency = 0.3
        .Line.ForeColor.RGB = RGB(150, 40, 40)
        .Line.Weight = 0.75
        .Line.Transparency = 0.3
    End With
End Sub

Private Sub SetHeatText(ByVal shp As Shape, ByVal txt As String)
    With shp.TextFrame2
        .MarginLeft = 0: .MarginRight = 0: .MarginTop = 0: .MarginBottom = 0
        .WordWrap = msoFalse
        .VerticalAnchor = msoAnchorMiddle
        .TextRange.Text = txt
        If Len(txt) > 0 Then
            .TextRange.ParagraphFormat.Alignment = msoAlignCenter
            .TextRange.Font.Size = 8
            .TextRange.Font.Bold = msoTrue
            .TextRange.Font.Fill.ForeColor.RGB = RGB(0, 0, 0)
        End If
    End With
End Sub

Public Sub ClearHeatDisplay()
    'Xoa heatmap: chi cham vao cac o co du lieu (nhanh)
    Dim ws As Worksheet, old As Object, k As Variant, p() As String, shp As Shape
    If Not mHeat Is Nothing Then
        Set ws = GetSheet(SH_MAP)
        EnsureSelection
        Set old = mHeat
        Set mHeat = Nothing                    'de SetCellHighlight ve lai mau mac dinh
        For Each k In old.Keys
            p = Split(CStr(k), ",")
            Set shp = FindShape(ws, GRID_PREFIX & "R" & p(0) & "_C" & p(1))
            If Not shp Is Nothing Then
                SetHeatText shp, ""
                SetCellHighlight shp, gSelectedCells.Exists(CStr(k))
            End If
        Next k
    End If
    mHeatMax = 0
    mHeatActive = False
End Sub

Public Sub ShowDatabaseOnGrid(Optional ByVal silent As Boolean = False)
    Dim ws As Worksheet, lo As ListObject, dat As Variant, i As Long, tmp As Variant
    Dim cMod As Long, cX As Long, cY As Long, cQty As Long, cSD As Long, cSh As Long, cVin As Long, cDef As Long
    Dim model As String, fVin As String, fShift As String, fDef As String, useRecords As Boolean
    Dim hasFrom As Boolean, hasTo As Boolean, dFrom As Long, dTo As Long, sd As Long
    Dim agg As Object, key As String, r As Long, c As Long, v As Double, nR As Long, nC As Long
    Dim k As Variant, p() As String, shp As Shape, nSkip As Long, totalV As Double, maxV As Double
    Dim prevSU As Boolean, st As String

    On Error GoTo EH
    prevSU = Application.ScreenUpdating
    Application.ScreenUpdating = False
    Set ws = GetSheet(SH_MAP)

    CloseCalendar
    model = Trim$(CStr(ws.Range("B2").Value))
    If Len(model) = 0 Then
        If Not silent Then MsgBox "Chua chon Model (o B2).", vbExclamation, "Xem du lieu"
        GoTo CLEANUP
    End If
    If StrComp(GetGridModel(ws), model, vbTextCompare) <> 0 Then
        If Not silent Then MsgBox "Grid hien tai khong thuoc Model '" & model & "'. Hay chon lai Model o B2.", vbExclamation, "Xem du lieu"
        GoTo CLEANUP
    End If
    nR = gRows: nC = gCols
    If nR < 1 Then nR = CLng(Val(CStr(ws.Range("B5").Value)))
    If nC < 1 Then nC = CLng(Val(CStr(ws.Range("B6").Value)))

    'Doc bo loc
    tmp = ws.Range("B21").Value
    If Len(Trim$(CStr(tmp))) > 0 Then
        If Not IsDate(tmp) Then
            If Not silent Then MsgBox "From date (B21) khong phai ngay hop le.", vbExclamation, "Xem du lieu"
            GoTo CLEANUP
        End If
        hasFrom = True: dFrom = CLng(Int(CDbl(CDate(tmp))))
    End If
    tmp = ws.Range("B22").Value
    If Len(Trim$(CStr(tmp))) > 0 Then
        If Not IsDate(tmp) Then
            If Not silent Then MsgBox "To date (B22) khong phai ngay hop le.", vbExclamation, "Xem du lieu"
            GoTo CLEANUP
        End If
        hasTo = True: dTo = CLng(Int(CDbl(CDate(tmp))))
    End If
    If hasFrom And hasTo Then
        If dFrom > dTo Then
            If Not silent Then MsgBox "From date lon hon To date.", vbExclamation, "Xem du lieu"
            GoTo CLEANUP
        End If
    End If
    fVin = Trim$(CStr(ws.Range("B23").Value))
    fShift = UCase$(Trim$(CStr(ws.Range("B24").Value)))
    fDef = Trim$(CStr(ws.Range("B25").Value))
    useRecords = (LCase$(Trim$(CStr(ws.Range("B26").Value))) = "records")

    'Tong hop theo o (X = cot, Y = hang)
    Set agg = CreateObject("Scripting.Dictionary")
    Set lo = GetTable(SH_DB, TBL_DEFECTS)
    If TableHasData(lo) Then
        cMod = colIdx(lo, "Model"): cX = colIdx(lo, "X"): cY = colIdx(lo, "Y"): cQty = colIdx(lo, "Qty")
        cSD = colIdx(lo, "ShiftDate"): cSh = colIdx(lo, "Shift"): cVin = colIdx(lo, "VIN"): cDef = colIdx(lo, "DefectType")
        dat = lo.DataBodyRange.Value2
        For i = 1 To UBound(dat, 1)
            If StrComp(Trim$(CStr(dat(i, cMod))), model, vbTextCompare) = 0 Then
                If Len(fVin) > 0 Then
                    If StrComp(Trim$(CStr(dat(i, cVin))), fVin, vbTextCompare) <> 0 Then GoTo NextRow
                End If
                If Len(fShift) > 0 Then
                    If UCase$(Trim$(CStr(dat(i, cSh)))) <> fShift Then GoTo NextRow
                End If
                If Len(fDef) > 0 Then
                    If StrComp(Trim$(CStr(dat(i, cDef))), fDef, vbTextCompare) <> 0 Then GoTo NextRow
                End If
                If hasFrom Or hasTo Then
                    sd = 0
                    If IsNumeric(dat(i, cSD)) Then
                        sd = CLng(dat(i, cSD))
                    ElseIf IsDate(dat(i, cSD)) Then
                        sd = CLng(Int(CDbl(CDate(dat(i, cSD)))))
                    End If
                    If hasFrom Then
                        If sd < dFrom Then GoTo NextRow
                    End If
                    If hasTo Then
                        If sd > dTo Then GoTo NextRow
                    End If
                End If
                If Not (IsNumeric(dat(i, cX)) And IsNumeric(dat(i, cY))) Then GoTo NextRow
                c = CLng(dat(i, cX)): r = CLng(dat(i, cY))
                If r < 1 Or r > nR Or c < 1 Or c > nC Then
                    nSkip = nSkip + 1
                    GoTo NextRow
                End If
                If useRecords Then
                    v = 1
                ElseIf IsNumeric(dat(i, cQty)) Then
                    v = CDbl(dat(i, cQty))
                Else
                    v = 0
                End If
                key = r & "," & c
                If agg.Exists(key) Then agg(key) = agg(key) + v Else agg.Add key, v
            End If
NextRow:
        Next i
    End If

    'Ve lai: xoa heatmap cu, roi to mau cac o co du lieu
    ClearHeatDisplay
    EnsureSelection
    For Each k In agg.Keys
        If agg(k) > maxV Then maxV = agg(k)
        totalV = totalV + agg(k)
    Next k
    Set mHeat = agg
    mHeatMax = maxV
    mHeatActive = True
    For Each k In agg.Keys
        p = Split(CStr(k), ",")
        Set shp = FindShape(ws, GRID_PREFIX & "R" & p(0) & "_C" & p(1))
        If Not shp Is Nothing Then
            SetHeatText shp, CStr(CLng(agg(k)))
            SetCellHighlight shp, gSelectedCells.Exists(CStr(k))
        End If
    Next k

    st = "Model " & model & ": " & agg.Count & " o co loi  |  Tong " & IIf(useRecords, "Records", "Qty") & " = " & CLng(totalV)
    If nSkip > 0 Then st = st & "  |  bo qua " & nSkip & " ban ghi ngoai Grid"
    If agg.Count = 0 Then st = "Khong co du lieu phu hop bo loc cho Model " & model
    ws.Range("A29").Value = st

CLEANUP:
    Application.ScreenUpdating = prevSU
    Exit Sub
EH:
    Application.ScreenUpdating = prevSU
    MsgBox "ShowDatabaseOnGrid loi: " & Err.Description, vbCritical
End Sub

Private Function CalShape(ByVal ws As Worksheet, ByVal nm As String, ByVal txt As String, _
                          ByVal l As Double, ByVal tp As Double, ByVal w As Double, ByVal h As Double, _
                          ByVal fillClr As Long, ByVal fontClr As Long, ByVal isBold As Boolean, _
                          Optional ByVal action As String = "") As Shape
    Dim s As Shape
    Set s = ws.Shapes.AddShape(msoShapeRectangle, l, tp, w, h)
    s.Name = nm
    s.Fill.ForeColor.RGB = fillClr
    s.Line.ForeColor.RGB = RGB(190, 190, 190)
    s.Line.Weight = 0.5
    On Error Resume Next
    s.Shadow.Visible = msoFalse
    s.Placement = xlFreeFloating
    Err.Clear
    On Error GoTo 0
    If Len(action) > 0 Then s.OnAction = action
    With s.TextFrame2
        .MarginLeft = 0: .MarginRight = 0: .MarginTop = 0: .MarginBottom = 0
        .WordWrap = msoFalse
        .VerticalAnchor = msoAnchorMiddle
        .TextRange.Text = txt
        If Len(txt) > 0 Then
            .TextRange.ParagraphFormat.Alignment = msoAlignCenter
            .TextRange.Font.Size = 9
            .TextRange.Font.Bold = IIf(isBold, msoTrue, msoFalse)
            .TextRange.Font.Fill.ForeColor.RGB = fontClr
        End If
    End With
    mCalCol.Add nm
    Set CalShape = s
End Function

Private Sub DeleteCalendarShapes()
    Dim ws As Worksheet, nm() As Variant, i As Long
    Set ws = GetSheet(SH_MAP)
    If Not mCalCol Is Nothing Then
        If mCalCol.Count > 0 Then
            ReDim nm(0 To mCalCol.Count - 1)
            For i = 1 To mCalCol.Count
                nm(i - 1) = CStr(mCalCol(i))
            Next i
            On Error Resume Next
            ws.Shapes.Range(nm).Delete
            Err.Clear
            On Error GoTo 0
        End If
    End If
    Set mCalCol = Nothing
    If Not FindShape(ws, "CAL_BG") Is Nothing Then      'con sot (vd: mat trang thai) -> duyet tung shape
        For i = ws.Shapes.Count To 1 Step -1
            If Left$(ws.Shapes(i).Name, 4) = "CAL_" Then ws.Shapes(i).Delete
        Next i
    End If
End Sub

Private Sub DrawCalendar()
    Dim ws As Worksheet, d As Long, nDays As Long, idx As Long, wd As Long, i As Long
    Dim L0 As Double, T0 As Double, cw As Double, rh As Double, pad As Double
    Dim w As Double, hTotal As Double, yTop As Double, yBot As Double, bw As Double
    Dim cur As Variant, curSerial As Long, todaySerial As Long, serial As Long, fillClr As Long
    Dim wdNames As Variant, s As Shape

    Set ws = GetSheet(SH_MAP)
    DeleteCalendarShapes
    Set mCalCol = New Collection

    cw = 34: rh = 24: pad = 6
    w = 7 * cw + 2 * pad
    hTotal = pad + 26 + 20 + 6 * rh + 26 + pad
    L0 = ws.Range("C21").Left
    T0 = ws.Range(mCalTarget).Top
    yTop = T0 + pad
    yBot = yTop + 46 + 6 * rh

    cur = ws.Range(mCalTarget).Value
    If IsDate(cur) Then curSerial = CLng(Int(CDbl(CDate(cur))))
    todaySerial = CLng(Int(CDbl(Date)))

    Set s = CalShape(ws, "CAL_BG", "", L0, T0, w, hTotal, RGB(245, 245, 245), 0, False)
    s.Line.ForeColor.RGB = RGB(31, 56, 100)
    s.Line.Weight = 1.5

    CalShape ws, "CAL_NAV_PREV", "<", L0 + pad, yTop, cw, 26, RGB(31, 78, 121), RGB(255, 255, 255), True, "Cal_Nav"
    CalShape ws, "CAL_TITLE", "Thang " & mCalMonth & "/" & mCalYear, L0 + pad + cw, yTop, 5 * cw, 26, RGB(31, 56, 100), RGB(255, 255, 255), True
    CalShape ws, "CAL_NAV_NEXT", ">", L0 + pad + 6 * cw, yTop, cw, 26, RGB(31, 78, 121), RGB(255, 255, 255), True, "Cal_Nav"

    wdNames = Array("T2", "T3", "T4", "T5", "T6", "T7", "CN")
    For i = 0 To 6
        If i = 6 Then fillClr = RGB(192, 0, 0) Else fillClr = RGB(0, 0, 0)
        CalShape ws, "CAL_WD" & (i + 1), CStr(wdNames(i)), L0 + pad + i * cw, yTop + 26, cw, 20, RGB(217, 217, 217), fillClr, True
    Next i

    nDays = Day(DateSerial(mCalYear, mCalMonth + 1, 0))
    wd = Weekday(DateSerial(mCalYear, mCalMonth, 1), vbMonday) - 1      '0 = thu hai
    For d = 1 To nDays
        idx = wd + d - 1
        serial = CLng(DateSerial(mCalYear, mCalMonth, d))
        fillClr = RGB(255, 255, 255)
        If serial = todaySerial Then fillClr = RGB(255, 230, 153)
        If serial = curSerial Then fillClr = RGB(146, 208, 80)
        CalShape ws, "CAL_D" & d, CStr(d), L0 + pad + (idx Mod 7) * cw, yTop + 46 + (idx \ 7) * rh, cw, rh, _
                 fillClr, RGB(0, 0, 0), (serial = curSerial), "Cal_DayClick"
    Next d

    bw = 7 * cw / 3
    CalShape ws, "CAL_BTN_TODAY", "Today", L0 + pad, yBot, bw, 26, RGB(0, 140, 70), RGB(255, 255, 255), True, "Cal_Today"
    CalShape ws, "CAL_BTN_CLEAR", "Delete", L0 + pad + bw, yBot, bw, 26, RGB(120, 120, 120), RGB(255, 255, 255), True, "Cal_Clear"
    CalShape ws, "CAL_BTN_CLOSE", "Close", L0 + pad + 2 * bw, yBot, bw, 26, RGB(160, 30, 30), RGB(255, 255, 255), True, "Cal_Close"
End Sub

Public Sub RefreshSummary()
    Dim loD As ListObject, loS As ListObject, ws As Worksheet, dat As Variant, dict As Object
    Dim i As Long, j As Long, m As Long, key As String, v As Variant, arr() As Variant
    Dim cMod As Long, cSD As Long, cSh As Long, cCell As Long, cX As Long, cY As Long, cDef As Long, cQty As Long
    Dim sIx(1 To 9) As Long, sHdr As Variant, sd As Long, qty As Double
    Dim nOld As Long, n As Long, newRows As Long, prevEv As Boolean

    prevEv = Application.EnableEvents
    On Error GoTo EH
    Application.EnableEvents = False
    Set loD = GetTable(SH_DB, TBL_DEFECTS)
    Set loS = GetTable(SH_SUM, TBL_SUMMARY)
    Set ws = GetSheet(SH_SUM)
    Set dict = CreateObject("Scripting.Dictionary")

    If TableHasData(loD) Then
        cMod = colIdx(loD, "Model"): cSD = colIdx(loD, "ShiftDate"): cSh = colIdx(loD, "Shift")
        cCell = colIdx(loD, "CellID"): cX = colIdx(loD, "X"): cY = colIdx(loD, "Y")
        cDef = colIdx(loD, "DefectType"): cQty = colIdx(loD, "Qty")
        dat = loD.DataBodyRange.Value2
        For i = 1 To UBound(dat, 1)
            If Len(CStr(dat(i, cMod))) > 0 Then
                If IsNumeric(dat(i, cSD)) Then
                    sd = CLng(dat(i, cSD))
                Else
                    sd = CLng(CDate(dat(i, cSD)))
                End If
                qty = 0
                If IsNumeric(dat(i, cQty)) Then qty = CDbl(dat(i, cQty))
                key = CStr(dat(i, cMod)) & "|" & sd & "|" & CStr(dat(i, cSh)) & "|" & _
                      CStr(dat(i, cCell)) & "|" & CStr(dat(i, cDef))
                If dict.Exists(key) Then
                    v = dict(key)
                    v(8) = v(8) + qty
                    v(9) = v(9) + 1
                    dict(key) = v
                Else
                    ReDim v(1 To 9)
                    v(1) = CStr(dat(i, cMod))
                    v(2) = sd
                    v(3) = CStr(dat(i, cSh))
                    v(4) = CStr(dat(i, cCell))
                    v(5) = dat(i, cX)
                    v(6) = dat(i, cY)
                    v(7) = CStr(dat(i, cDef))
                    v(8) = qty
                    v(9) = 1
                    dict.Add key, v
                End If
            End If
        Next i
    End If

    sHdr = Array("Model", "ShiftDate", "Shift", "CellID", "X", "Y", "DefectType", "TotalQty", "RecordCount")
    For m = 0 To 8
        sIx(m + 1) = colIdx(loS, CStr(sHdr(m)))
    Next m

    nOld = 0
    If Not loS.DataBodyRange Is Nothing Then
        nOld = loS.DataBodyRange.Rows.Count
        loS.DataBodyRange.ClearContents
    End If
    n = dict.Count
    newRows = n
    If newRows < 1 Then newRows = 1
    loS.Resize loS.Range.Resize(newRows + 1)
    If nOld > newRows Then
        ws.Rows((loS.Range.Row + newRows + 1) & ":" & (loS.Range.Row + nOld)).Delete
    End If

    If n > 0 Then
        ReDim arr(1 To n, 1 To loS.ListColumns.Count)
        j = 0
        Dim k As Variant
        For Each k In dict.Keys
            j = j + 1
            v = dict(k)
            For m = 1 To 9
                arr(j, sIx(m)) = v(m)
            Next m
        Next k
        loS.ListColumns(sIx(2)).DataBodyRange.NumberFormat = "dd/mm/yyyy"
        loS.DataBodyRange.Value = arr
    End If
CLEANUP:
    Application.EnableEvents = prevEv
    Exit Sub
EH:
    Dim eN As Long, eD As String
    eN = Err.Number: eD = Err.Description
    Application.EnableEvents = prevEv
    Err.Raise eN, "RefreshSummary", eD
End Sub

Private Function FindBlankSheet() As Worksheet
    Dim ws As Worksheet
    For Each ws In ThisWorkbook.Worksheets
        If StrComp(ws.Name, SH_MAP, vbTextCompare) <> 0 And StrComp(ws.Name, SH_MASTER, vbTextCompare) <> 0 And _
           StrComp(ws.Name, SH_DB, vbTextCompare) <> 0 And StrComp(ws.Name, SH_SUM, vbTextCompare) <> 0 And _
           StrComp(ws.Name, "Dashboard", vbTextCompare) <> 0 And StrComp(ws.Name, "Config", vbTextCompare) <> 0 And _
           StrComp(ws.Name, "DASH_CALC", vbTextCompare) <> 0 Then
            If Application.WorksheetFunction.CountA(ws.Cells) = 0 And ws.Shapes.Count = 0 Then
                Set FindBlankSheet = ws: Exit Function
            End If
        End If
    Next ws
End Function

Private Sub EnsureSheets()
    Dim names As Variant, i As Long, ws As Worksheet
    names = Array(SH_MAP, SH_MASTER, SH_DB, SH_SUM)
    For i = 0 To 3
        If Not SheetExists(CStr(names(i))) Then
            Set ws = FindBlankSheet()
            If ws Is Nothing Then
                Set ws = ThisWorkbook.Worksheets.Add(After:=ThisWorkbook.Worksheets(ThisWorkbook.Worksheets.Count))
            End If
            ws.Name = CStr(names(i))
        End If
    Next i
    For i = 3 To 0 Step -1
        ThisWorkbook.Worksheets(CStr(names(i))).Move Before:=ThisWorkbook.Worksheets(1)
    Next i
    'Xoa sheet thua con trong (chi giu dung 4 sheet)
    Application.DisplayAlerts = False
    Do
        Set ws = FindBlankSheet()
        If ws Is Nothing Then Exit Do
        ws.Delete
    Loop
    Application.DisplayAlerts = True
End Sub

Private Function EnsureTable(ByVal ws As Worksheet, ByVal tblName As String, ByVal topLeft As String, _
                             ByVal headers As Variant, Optional ByVal rowsData As Variant) As ListObject
    Dim lo As ListObject, i As Long, j As Long, nCols As Long, nRows As Long, rng As Range
    On Error Resume Next
    Set lo = ws.ListObjects(tblName)
    On Error GoTo 0
    If Not lo Is Nothing Then Set EnsureTable = lo: Exit Function

    nCols = UBound(headers) - LBound(headers) + 1
    nRows = 1
    If Not IsMissing(rowsData) Then nRows = UBound(rowsData) - LBound(rowsData) + 1
    Set rng = ws.Range(topLeft).Resize(nRows + 1, nCols)
    For j = 0 To nCols - 1
        rng.Cells(1, j + 1).Value = headers(LBound(headers) + j)
    Next j
    If Not IsMissing(rowsData) Then
        For i = 0 To nRows - 1
            For j = 0 To nCols - 1
                rng.Cells(i + 2, j + 1).Value = rowsData(LBound(rowsData) + i)(j)
            Next j
        Next i
    End If
    Set lo = ws.ListObjects.Add(xlSrcRange, rng, , xlYes)
    lo.Name = tblName
    lo.TableStyle = "TableStyleMedium2"
    Set EnsureTable = lo
End Function

Public Function DashEnsureTable(ByVal ws As Worksheet, ByVal tblName As String, ByVal topLeft As String, _

    Set lo = ws.ListObjects.Add(xlSrcRange, rng, , xlYes)

    Set DashEnsureTable = lo

Public Function SortDictKeys(ByVal d As Object, ByRef ks() As String, ByRef vs() As Double, ByVal descending As Boolean) As Long
    'Sap xep khoa theo gia tri (giam dan neu descending), bang nhau thi theo ten tang dan. Tra ve so phan tu.
    Dim n As Long, i As Long, j As Long, k As Variant, tk As String, tv As Double, moveIt As Boolean
    n = d.Count
    If n = 0 Then
        ReDim ks(1 To 1): ReDim vs(1 To 1)
        Exit Function
    End If
    ReDim ks(1 To n): ReDim vs(1 To n)
    i = 0
    For Each k In d.Keys
        i = i + 1
        ks(i) = CStr(k)
        vs(i) = CDbl(d(k))
    Next k
    For i = 2 To n
        tk = ks(i): tv = vs(i)
        j = i - 1
        Do While j >= 1
            If vs(j) = tv Then
                moveIt = (StrComp(ks(j), tk, vbTextCompare) > 0)
            ElseIf descending Then
                moveIt = (vs(j) < tv)
            Else
                moveIt = (vs(j) > tv)
            End If
            If Not moveIt Then Exit Do
            ks(j + 1) = ks(j): vs(j + 1) = vs(j)
            j = j - 1
        Loop
        ks(j + 1) = tk: vs(j + 1) = tv
    Next i
    SortDictKeys = n
End Function

Public Function Top3(ByVal d As Object, ByVal tie As Object, ByRef nm() As String, ByRef ct() As Double) As Long
    'Top 3 khoa co gia tri lon nhat. Bang nhau -> khoa co gia tri tie nho hon (hang truoc, cot truoc) xep truoc.
    Dim r As Long, k As Variant, best As String, bestV As Double, bestT As Double
    Dim found As Boolean, v As Double, t As Double, used As Object
    ReDim nm(1 To 3): ReDim ct(1 To 3)
    Set used = NewDict()
    For r = 1 To 3
        found = False
        For Each k In d.Keys
            If Not used.Exists(CStr(k)) Then
                v = CDbl(d(k))
                t = 0
                If tie.Exists(CStr(k)) Then t = CDbl(tie(CStr(k)))
                If Not found Then
                    best = CStr(k): bestV = v: bestT = t: found = True
                ElseIf v > bestV Or (v = bestV And t < bestT) Then
                    best = CStr(k): bestV = v: bestT = t
                End If
            End If
        Next k
        If Not found Then Exit For
        used.Add best, True
        nm(r) = best
        ct(r) = bestV
        Top3 = r
    Next r
End Function

Public Sub SyncDefectColors(ByVal names As Object)
    Dim lo As ListObject, i As Long, nm As String, clr As Long, k As Variant, r As ListRow
    Dim body As Range, emptyRow As Long
    Set gDefColors = NewDict()
    Set lo = DashTryTable(SH_CFG, TBL_DCOL)
    If lo Is Nothing Then Exit Sub

    If Not lo.DataBodyRange Is Nothing Then
        Set body = lo.DataBodyRange
        For i = 1 To body.Rows.Count
            nm = Trim$(CStr(body.Cells(i, 1).Value))
            If Len(nm) > 0 Then
                If Not gDefColors.Exists(nm) Then
                    clr = body.Cells(i, 2).Interior.Color
                    If clr = 16777215 Then                   'chua gan mau -> gan mau mac dinh
                        clr = PaletteColor(gDefColors.Count)
                        body.Cells(i, 2).Interior.Color = clr
                    End If
                    gDefColors.Add nm, clr
                End If
            End If
        Next i
    End If

    For Each k In names.Keys
        nm = CStr(k)
        If Not gDefColors.Exists(nm) Then
            clr = PaletteColor(gDefColors.Count)
            emptyRow = 0
            If Not lo.DataBodyRange Is Nothing Then
                For i = 1 To lo.DataBodyRange.Rows.Count
                    If Len(Trim$(CStr(lo.DataBodyRange.Cells(i, 1).Value))) = 0 Then emptyRow = i: Exit For
                Next i
            End If
            If emptyRow > 0 Then
                lo.DataBodyRange.Cells(emptyRow, 1).Value = nm
                lo.DataBodyRange.Cells(emptyRow, 2).Interior.Color = clr
            Else
                Set r = lo.ListRows.Add
                r.Range.Cells(1, 1).Value = nm
                r.Range.Cells(1, 2).Interior.Color = clr
            End If
            gDefColors.Add nm, clr
        End If
    Next k
End Sub

Private Function FilterText(ByVal v As Variant) As String
    Dim s As String
    If IsError(v) Then Exit Function
    s = Trim$(CStr(v))
    If LCase$(s) = "all" Then s = ""
    FilterText = s
End Function

Public Function ReadFilters(ByRef msg As String) As Boolean
    Dim ws As Worksheet, v As Variant, days As Long
    Set ws = DashSheet(SH_DASH)

    days = CLng(Val(CStr(CfgValue("DefaultDays", 30))))
    If days < 1 Then days = 30

    v = ws.Range(F_TO).Value
    If IsDate(v) Then fTo = CLng(Int(CDbl(CDate(v)))) Else fTo = CLng(Int(CDbl(Date)))
    v = ws.Range(F_FROM).Value
    If IsDate(v) Then fFrom = CLng(Int(CDbl(CDate(v)))) Else fFrom = fTo - days + 1
    If fFrom > fTo Then
        msg = "From date lon hon To date. Hay chon lai khoang ngay."
        Exit Function
    End If
    pTo = fFrom - 1
    pFrom = fFrom - (fTo - fFrom + 1)

    fModel = FilterText(ws.Range(F_MODEL).Value)
    fShift = UCase$(FilterText(ws.Range(F_SHIFT).Value))
    fDef = FilterText(ws.Range(F_DEF).Value)
    fCell = FilterText(ws.Range(F_CELL).Value)

    fTopN = CLng(Val(CStr(ws.Range(F_TOPN).Value)))
    If fTopN < 1 Then fTopN = CLng(Val(CStr(CfgValue("TopN", 5))))
    If fTopN < 1 Then fTopN = 5
    If fTopN > 10 Then fTopN = 10
    ReadFilters = True
End Function

Private Function PassBase(ByVal mdl As String, ByVal sh As String, ByVal df As String, ByVal cl As String) As Boolean
    If Len(fModel) > 0 Then
        If StrComp(mdl, fModel, vbTextCompare) <> 0 Then Exit Function
    End If
    If Len(fShift) > 0 Then
        If StrComp(sh, fShift, vbTextCompare) <> 0 Then Exit Function
    End If
    If Len(fDef) > 0 Then
        If StrComp(df, fDef, vbTextCompare) <> 0 Then Exit Function
    End If
    If Len(fCell) > 0 Then
        If StrComp(cl, fCell, vbTextCompare) <> 0 Then Exit Function
    End If
    PassBase = True
End Function

Private Function ParseRow(ByRef src As Variant, ByVal i As Long, ByRef sd As Long, ByRef sh As String, _
                          ByRef mdl As String, ByRef vn As String, ByRef df As String, ByRef cl As String, _
                          ByRef q As Double) As Boolean
    'Tra ve False neu dong khong hop le (thieu Model/VIN/Defect/Cell, Qty sai, khong xac dinh duoc ngay/ca)
    Dim v As Variant, dt As Date, hasDT As Boolean, pd As Date, sn As String
    On Error GoTo Bad

    mdl = Trim$(CStr(src(i, cMod)))
    vn = Trim$(CStr(src(i, cVin)))
    df = Trim$(CStr(src(i, cDef)))
    cl = Trim$(CStr(src(i, cCell)))
    If Len(mdl) = 0 Or Len(vn) = 0 Or Len(df) = 0 Or Len(cl) = 0 Then Exit Function

    If mCountRecords Then
        q = 1
    Else
        v = src(i, cQty)
        If IsError(v) Then Exit Function
        If IsEmpty(v) Then Exit Function
        If Not IsNumeric(v) Then Exit Function
        q = CDbl(v)
        If q <= 0 Then Exit Function
    End If

    v = src(i, cDT)
    If Not IsEmpty(v) And Not IsError(v) Then
        If IsNumeric(v) Then
            If CDbl(v) > 0 Then dt = CDate(CDbl(v)): hasDT = True
        ElseIf IsDate(v) Then
            dt = CDate(v): hasDT = True
        End If
    End If

    sd = 0
    v = src(i, cSD)
    If Not IsEmpty(v) And Not IsError(v) Then
        If IsNumeric(v) Then
            If CDbl(v) > 0 Then sd = CLng(Int(CDbl(v)))
        ElseIf IsDate(v) Then
            sd = CLng(Int(CDbl(CDate(v))))
        End If
    End If

    sh = UCase$(Trim$(CStr(src(i, cSh))))
    If hasDT And (sd = 0 Or Len(sh) = 0) Then
        GetShiftInfo dt, sn, pd                    'ham co san trong modVehicleMapping
        If sd = 0 Then sd = CLng(Int(CDbl(pd)))
        If Len(sh) = 0 Then sh = sn
    End If
    If sd = 0 Or Len(sh) = 0 Then Exit Function
    ParseRow = True
    Exit Function
Bad:
    ParseRow = False
End Function

Private Function CellSortKey(ByVal x As Variant, ByVal y As Variant) As Double
    CellSortKey = 99999999
    If IsEmpty(x) Or IsEmpty(y) Or IsError(x) Or IsError(y) Then Exit Function
    If IsNumeric(x) And IsNumeric(y) Then CellSortKey = CDbl(y) * 10000# + CDbl(x)
End Function

Public Function LoadAndAggregate() As Boolean
    Dim lo As ListObject, src As Variant, n As Long, i As Long, j As Long
    Dim sd As Long, sh As String, mdl As String, vn As String, df As String, cl As String, q As Double, pc As String
    Dim maxDetail As Long, d() As Variant, t() As Variant, a As Long, b As Long
    Dim firstRow As Long

    ResetResults
    gDashStep = "doc tblDefects"
    Set lo = DashTable(SH_DB, TBL_DEFECTS)
    InitCols lo
    If lo.DataBodyRange Is Nothing Then
        LoadAndAggregate = True
        GoTo Finish
    End If
    firstRow = lo.DataBodyRange.Row
    src = lo.DataBodyRange.Value2
    n = UBound(src, 1)

    gDashStep = "tong hop du lieu"
    For i = 1 To n
        If IsEmpty(src(i, cMod)) And IsEmpty(src(i, cVin)) And IsEmpty(src(i, cDef)) Then GoTo NextRow   'dong trong
        rRows = rRows + 1
        If Not ParseRow(src, i, sd, sh, mdl, vn, df, cl, q) Then
            rSkipped = rSkipped + 1
            If rFirstBad = 0 Then rFirstBad = firstRow + i - 1
            GoTo NextRow
        End If

        lModels(mdl) = True
        lDefects(df) = True
        lShifts(sh) = True
        If Not lCells.Exists(cl) Then lCells.Add cl, CellSortKey(src(i, cX), src(i, cY))

        If Not PassBase(mdl, sh, df, cl) Then GoTo NextRow

        If sd >= fFrom And sd <= fTo Then
            rMatch = rMatch + 1
            rTotal = rTotal + q
            rVin(vn) = True
            AddTo rDefQty, df, q
            AddNested rDefVin, df, vn, 1
            AddTo rDateShift, sd & "|" & sh, q
            AddTo rDateQty, CStr(sd), q
            AddNested rDateVin, CStr(sd), vn, 1
            pc = ""
            If cColor > 0 Then
                If Not IsError(src(i, cColor)) Then pc = Trim$(CStr(src(i, cColor)))
            End If
            If Len(pc) = 0 Then pc = "(Chua ghi mau)"
            AddTo rColorQty, pc, q
            AddNested rColorVin, pc, vn, 1
            AddTo rDateDef, sd & "|" & df, q
            AddTo rShiftQty, sh, q
            AddNested rShiftVin, sh, vn, 1
            AddTo rModelQty, mdl, q
            AddNested rModelCell, mdl, cl, q
            AddNested rDefCell, df, cl, q
            AddTo rCellQty, cl, q
            AddTo rMatrix, df & "|" & mdl, q
            If Not IsError(src(i, cX)) And Not IsError(src(i, cY)) Then
                If IsNumeric(src(i, cX)) And IsNumeric(src(i, cY)) Then
                    If Not IsEmpty(src(i, cX)) And Not IsEmpty(src(i, cY)) Then
                        AddTo rHeat, mdl & "|" & df & "|" & CLng(src(i, cY)) & "," & CLng(src(i, cX)), q
                    End If
                End If
            End If
        ElseIf sd >= pFrom And sd <= pTo Then
            AddTo rDefPrev, df, q
        End If
NextRow:
    Next i

    'Bang chi tiet: lay cac dong moi nhat khop bo loc (duyet tu cuoi len)
    gDashStep = "bang chi tiet"
    maxDetail = CLng(Val(CStr(CfgValue("DetailMaxRows", 500))))
    If maxDetail < 1 Then maxDetail = 500
    If maxDetail > 5000 Then maxDetail = 5000
    If rMatch > 0 Then
        If maxDetail > rMatch Then maxDetail = rMatch
        ReDim d(1 To maxDetail, 1 To 12)
        j = 0
        For i = n To 1 Step -1
            If ParseRow(src, i, sd, sh, mdl, vn, df, cl, q) Then
                If PassBase(mdl, sh, df, cl) Then
                    If sd >= fFrom And sd <= fTo Then
                        j = j + 1
                        d(j, 1) = CDbl(sd)
                        d(j, 2) = src(i, cDT)
                        d(j, 3) = sh
                        d(j, 4) = mdl
                        d(j, 5) = vn
                        d(j, 6) = df
                        d(j, 7) = src(i, cQty)
                        d(j, 8) = src(i, cY)
                        d(j, 9) = src(i, cX)
                        d(j, 10) = cl
                        If cIns > 0 Then d(j, 11) = src(i, cIns)
                        If cDesc > 0 Then d(j, 12) = src(i, cDesc)
                        If j >= maxDetail Then Exit For
                    End If
                End If
            End If
        Next i
        If j = maxDetail Then
            rDetail = d
        ElseIf j > 0 Then
            ReDim t(1 To j, 1 To 12)
            For a = 1 To j
                For b = 1 To 12
                    t(a, b) = d(a, b)
                Next b
            Next a
            rDetail = t
        End If
        rDetailN = j
    End If
    LoadAndAggregate = True

Finish:
    MergeMasterList TBL_MODELS, "Model", lModels
    MergeMasterList TBL_DEFECTTYPES, "DefectType", lDefects
End Function

Private Function ShiftNames(ByRef ks() As String) As Long
    'Danh sach ca: tblShifts (Active = Yes); neu khong co thi lay tu du lieu
    Dim lo As ListObject, dat As Variant, i As Long, n As Long, cs As Long, cA As Long
    Dim vs() As Double
    Set lo = DashTryTable(SH_MASTER, TBL_SHIFTS)
    If Not lo Is Nothing Then
        If Not lo.DataBodyRange Is Nothing Then
            cs = DashColIndex(lo, "Shift", False)
            cA = DashColIndex(lo, "Active", False)
            If cs > 0 Then
                dat = lo.DataBodyRange.Value2
                ReDim ks(1 To UBound(dat, 1))
                For i = 1 To UBound(dat, 1)
                    If Len(Trim$(CStr(dat(i, cs)))) > 0 Then
                        If cA = 0 Then
                            n = n + 1: ks(n) = UCase$(Trim$(CStr(dat(i, cs))))
                        ElseIf IsActiveValue(dat(i, cA)) Then
                            n = n + 1: ks(n) = UCase$(Trim$(CStr(dat(i, cs))))
                        End If
                    End If
                Next i
            End If
        End If
    End If
    If n = 0 Then n = SortDictKeys(lShifts, ks, vs, True)
    ShiftNames = n

Private Sub FillPie(ByVal co As ChartObject, ByVal calc As Worksheet, ByVal c0 As Long, _
                    ByVal d As Object, ByVal byDefect As Boolean, ByVal hdr As String)
    Dim cht As Chart, s As Series, ks() As String, vs() As Double, n As Long, m As Long
    Dim i As Long, nOut As Long, others As Double, arr() As Variant, clr As Long
    Set cht = co.Chart
    ClearSeries cht
    calc.Range(calc.Cells(1, c0), calc.Cells(40, c0 + 1)).ClearContents
    n = SortDictKeys(d, ks, vs, True)
    If n = 0 Then
        co.Visible = False
        Exit Sub
    End If
    co.Visible = True

    If n > PIE_MAX_SLICES Then m = PIE_MAX_SLICES - 1 Else m = n
    For i = m + 1 To n
        others = others + vs(i)
    Next i
    nOut = m
    If others > 0 Then nOut = m + 1
    ReDim arr(1 To nOut + 1, 1 To 2)
    arr(1, 1) = hdr: arr(1, 2) = "Defects"
    For i = 1 To m
        arr(i + 1, 1) = ks(i): arr(i + 1, 2) = vs(i)
    Next i
    If others > 0 Then
        arr(nOut + 1, 1) = "Others": arr(nOut + 1, 2) = others
    End If
    calc.Cells(1, c0).Resize(nOut + 1, 2).Value = arr

    cht.ChartType = xlPie
    Set s = cht.SeriesCollection.NewSeries
    s.Name = "Defects"
    s.XValues = calc.Range(calc.Cells(2, c0), calc.Cells(nOut + 1, c0))
    s.Values = calc.Range(calc.Cells(2, c0 + 1), calc.Cells(nOut + 1, c0 + 1))
    s.HasDataLabels = True
    With s.DataLabels
        .ShowPercentage = True
        .ShowValue = False
        .ShowCategoryName = False
        .Position = xlLabelPositionOutsideEnd
        .Font.Size = 9
    End With
    For i = 1 To nOut
        If i > m Then
            clr = RGB(166, 166, 166)
        ElseIf byDefect Then
            clr = DefectColor(ks(i))
        Else
            clr = PaletteColor(i - 1)
        End If
        s.Points(i).Format.Fill.ForeColor.RGB = clr
        If rTotal > 0 Then
            s.Points(i).DataLabel.Text = CStr(Round(arr(i + 1, 2) / rTotal * 100, 1)) & "% (" & CStr(Round(arr(i + 1, 2), 2)) & "/" & CStr(Round(rTotal, 2)) & ")"
        End If
    Next i
    cht.HasLegend = True
    cht.Legend.Position = xlLegendPositionRight
End Sub

'=====================================================================
' VEHICLE DEFECT MAPPING - hinh xe + Grid, Top 3 o Grid nhieu loi nhat cua tung Defect Type (toi da HM_MAX_MODELS Model)
' - Du lieu: rHeat (Model|DefectType|hang,cot -> so loi) do LoadAndAggregate gop theo bo loc Dashboard.
' - Hinh xe: hinh Master (MASTER > tblModels > ImageShapeName) tren MAP_VEHICLE. Grid chia deu Rows x Cols cua Model
'   (giong CreateVehicleGrid o MAP_VEHICLE) nen o (r, c) = hinh chu nhat thu c / Cols, r / Rows cua hinh.
' - Ve: duong Grid mo, o Top 3 to mau Defect Type (hang 1 dam nhat) kem so thu hang, chu giai mau.
' - Vung ve: tu hang ROW_HM_FIRST, rong bang ca report (A:N), moi hang ngang 2 hinh; chieu cao vung Mapping TUY THEO so Model
'   (gRowHmLast). Cac bieu do va Defect Detail nam duoi Mapping nen cung dich theo (xem ArrangeBelowMapping o module chinh).
'=====================================================================
Public Sub UpdateHeatmap(ByVal showMsg As Boolean)
    Dim ws As Worksheet, mdl As Object, grp As Object, nSkip As Long, shown As Object
    Dim defs() As String, vsD() As Double, nAll As Long, nD As Long
    Dim cand() As String, candQ() As Double, nCand As Long, mods() As String, nM As Long, k As Variant
    Dim availW As Double, availH As Double, legendH As Double, hmAvail As Double
    Dim pics() As Shape, asp() As Double, perRow As Long, nTileRows As Long
    Dim i As Long, j As Long, tr As Long, tc As Long, tileW As Double, sumAsp As Double, mx As Double
    Dim yRow() As Double, x As Double, y As Double, tq As Double, ts As String
    Dim info As Variant, s As Shape, pic As Shape, dd As Long, rr As Long, nR As Long, nC As Long
    Dim t As Variant, key As String, occ As Object, n As Long, inset As Double
    Dim cw As Double, chh As Double, rowN As Long, colN As Long, v As Double, clr As Long, tip As String
    Dim noteTxt As String, hmLast As Long

    hmLast = ROW_HM_FIRST + HM_MIN_ROWS - 1       'chieu cao toi thieu; tang len sau khi ve cac hinh
    On Error GoTo EH
    Set ws = DashSheet(SH_DASH)
    availW = ws.Range("O1").Left - ws.Range("A1").Left - 8       'do rong = ca dai A:N cua report

    HmClearShapes ws
    noteTxt = "So 1-2-3 = thu hang o Grid nhieu loi nhat cua tung Defect Type (mau = Defect Type, xem chu giai). Re chuot len o de xem Cell ID va so loi."
    ws.Range("A" & ROW_HM_NOTE).Value = noteTxt

    If rHeat Is Nothing Then GoTo CLEANUP
    Set shown = NewDict()
    If rHeat.Count = 0 Or rModelQty.Count = 0 Then
        HmDeleteStalePics ws, shown
        ws.Range("A" & ROW_HM_NOTE).Value = "Khong co du lieu phu hop bo loc hien tai."
        GoTo CLEANUP
    End If

    Set mdl = HmReadModels()
    HmBuildTop3 mdl, grp, nSkip

    'Defect Type theo tong giam dan (toi da HM_MAX_TYPES)
    nAll = SortDictKeys(rDefQty, defs, vsD, True)
    nD = nAll
    If nD > HM_MAX_TYPES Then nD = HM_MAX_TYPES
    If nD = 0 Then GoTo CLEANUP

    'Model co du lieu, nhieu loi nhat truoc; chi lay toi da HM_MAX_MODELS
    ReDim cand(1 To mdl.Count + 1)
    ReDim candQ(1 To mdl.Count + 1)
    For Each k In mdl.Keys
        If rModelQty.Exists(CStr(k)) Then
            nCand = nCand + 1
            cand(nCand) = CStr(k)
            candQ(nCand) = CDbl(rModelQty(CStr(k)))
        End If
    Next k
    If nCand = 0 Then
        HmDeleteStalePics ws, shown
        ws.Range("A" & ROW_HM_NOTE).Value = "Model trong du lieu khong co trong MASTER > tblModels nen khong ve duoc mapping."
        GoTo CLEANUP
    End If
    For i = 1 To nCand - 1
        For j = i + 1 To nCand
            If candQ(j) > candQ(i) Then
                tq = candQ(i): candQ(i) = candQ(j): candQ(j) = tq
                ts = cand(i): cand(i) = cand(j): cand(j) = ts
            End If
        Next j
    Next i
    nM = nCand
    If nM > HM_MAX_MODELS Then nM = HM_MAX_MODELS
    ReDim mods(1 To nM)
    For i = 1 To nM
        mods(i) = cand(i)
        shown.Add mods(i), True
    Next i
    HmDeleteStalePics ws, shown
    If nCand > nM Then
        ws.Range("A" & ROW_HM_NOTE).Value = noteTxt & "  (Chi hien " & nM & "/" & nCand & " Model nhieu loi nhat)"
    End If

    'Hinh nen cho tung Model
    ReDim pics(1 To nM)
    ReDim asp(1 To nM)
    For i = 1 To nM
        info = mdl(mods(i))
        Set pics(i) = HmModelPicture(ws, mods(i), CStr(info(2)), showMsg)
        If pics(i) Is Nothing Then
            If showMsg Then MsgBox "Khong lay duoc hinh Master '" & CStr(info(2)) & "' cua Model " & mods(i) & ".", vbExclamation, "Dashboard"
            asp(i) = 0.5
        Else
            asp(i) = pics(i).Height / pics(i).Width
        End If
    Next i

    'Bo cuc: chu giai, roi cac hinh (tile): MOI HANG NGANG 2 HINH, do rong cua 2 hinh = do rong report (A:N)
    legendH = HmDrawLegend(ws, defs, nD, availW)
    perRow = 2
    nTileRows = (nM + perRow - 1) \ perRow
    tileW = (availW - HM_GAP * (perRow - 1)) / perRow
    ReDim yRow(0 To nTileRows - 1)
    For tr = 0 To nTileRows - 1
        mx = 0
        For tc = 0 To perRow - 1
            i = tr * perRow + tc + 1
            If i <= nM Then
                If asp(i) > mx Then mx = asp(i)
            End If
        Next tc
        sumAsp = sumAsp + mx
    Next tr

    y = ws.Rows(ROW_HM_FIRST).Top + 2 + legendH + 4
    For tr = 0 To nTileRows - 1
        yRow(tr) = y
        mx = 0
        For tc = 0 To perRow - 1
            i = tr * perRow + tc + 1
            If i <= nM Then
                If asp(i) > mx Then mx = asp(i)
            End If
        Next tc
        y = y + HM_TITLE_H + tileW * mx + HM_GAP
    Next tr
    'chieu cao vung Mapping (hang) = tu hang dau den het hinh cuoi
    hmLast = ROW_HM_FIRST + CLng((y - ws.Rows(ROW_HM_FIRST).Top) / ws.Rows(ROW_HM_FIRST).Height) + 1
    If hmLast < ROW_HM_FIRST + HM_MIN_ROWS - 1 Then hmLast = ROW_HM_FIRST + HM_MIN_ROWS - 1

    Set occ = CreateObject("Scripting.Dictionary")

    For i = 1 To nM
        tr = (i - 1) \ perRow
        tc = (i - 1) Mod perRow
        x = ws.Range("A1").Left + 2 + tc * (tileW + HM_GAP)
        info = mdl(mods(i))
        nR = CLng(info(0)): nC = CLng(info(1))

        'tieu de o
        Set s = ws.Shapes.AddShape(msoShapeRectangle, x, yRow(tr), tileW, HM_TITLE_H)
        With s
            .Name = "HM_T_" & mods(i)
            .Fill.ForeColor.RGB = RGB(31, 56, 100)
            .Line.Visible = msoFalse
            .Placement = xlMove
            With .TextFrame2
                .MarginLeft = 4: .MarginRight = 4: .MarginTop = 0: .MarginBottom = 0
                .VerticalAnchor = msoAnchorMiddle
                .WordWrap = msoFalse
                .TextRange.Text = mods(i) & "  (" & nR & " x " & nC & ")  -  " & Format$(CDbl(rModelQty(mods(i))), "#,##0") & " loi"
                .TextRange.Font.Size = 9
                .TextRange.Font.Bold = msoTrue
                .TextRange.Font.Fill.ForeColor.RGB = RGB(255, 255, 255)
                .TextRange.ParagraphFormat.Alignment = msoAlignLeft
            End With
        End With

        'hinh nen + Grid + o Top 3
        Set pic = pics(i)
        If Not pic Is Nothing Then
            With pic
                .LockAspectRatio = msoFalse
                .Left = x
                .Top = yRow(tr) + HM_TITLE_H
                .Width = tileW
                .Height = tileW * asp(i)
                .Line.Visible = msoTrue
                .Line.ForeColor.RGB = RGB(150, 150, 150)
                .Line.Weight = 0.75
            End With
            cw = pic.Width / nC
            chh = pic.Height / nR

            'duong Grid (mo)
            If HM_GRID_LINES Then
                For j = 1 To nC - 1
                    Set s = ws.Shapes.AddLine(pic.Left + j * cw, pic.Top, pic.Left + j * cw, pic.Top + pic.Height)
                    HmStyleGridLine s, "HM_G_" & i & "_C" & j
                Next j
                For j = 1 To nR - 1
                    Set s = ws.Shapes.AddLine(pic.Left, pic.Top + j * chh, pic.Left + pic.Width, pic.Top + j * chh)
                    HmStyleGridLine s, "HM_G_" & i & "_R" & j
                Next j
            End If

            'o Top 3 cho tung Defect Type (ve hang 3 truoc de hang 1 nam tren cung)
            For dd = 1 To nD
                key = mods(i) & "|" & defs(dd)
                If grp.Exists(key) Then
                    t = grp(key)
                    clr = DefectColor(defs(dd))
                    For rr = 3 To 1 Step -1
                        v = t(rr, 1)
                        If v > 0 Then
                            rowN = CLng(t(rr, 2)): colN = CLng(t(rr, 3))
                            n = 0
                            If occ.Exists(i & "|" & rowN & "," & colN) Then n = occ(i & "|" & rowN & "," & colN)
                            occ(i & "|" & rowN & "," & colN) = n + 1
                            inset = n * 2.5
                            Set s = ws.Shapes.AddShape(msoShapeRectangle, _
                                    pic.Left + (colN - 1) * cw + inset, pic.Top + (rowN - 1) * chh + inset, _
                                    HmMax(cw - 2 * inset, 4), HmMax(chh - 2 * inset, 4))
                            tip = mods(i) & " - " & defs(dd) & " - hang " & rr & " - " & ColumnLetter(colN) & rowN & " (" & CStr(CLng(v)) & " loi)"
                            HmStyleCell s, "HM_C_" & i & "_" & dd & "_" & rr, rr, clr, tip
                        End If
                    Next rr
                End If
            Next dd
        End If
    Next i

    If nSkip > 0 Then
        ws.Range("A" & ROW_HM_NOTE).Value = ws.Range("A" & ROW_HM_NOTE).Value & "  (Bo qua " & nSkip & " ban ghi ngoai Grid)"
    End If
CLEANUP:
    SetLayoutRows hmLast
    Application.CutCopyMode = False
    Exit Sub
EH:
    If showMsg Then MsgBox "Mapping loi: " & Err.Description, vbExclamation, "Dashboard"
    Resume CLEANUP
End Sub

Private Function HmMax(ByVal a As Double, ByVal b As Double) As Double
    If a > b Then HmMax = a Else HmMax = b
End Function

'Model -> Array(Rows, Cols, ImageShapeName), thu tu theo MASTER > tblModels
Private Function HmReadModels() As Object
    Dim d As Object, lo As ListObject, dat As Variant, i As Long, nm As String
    Dim cM As Long, cR As Long, cC As Long, cI As Long
    Set d = NewDict()
    Set lo = DashTable(SH_MASTER, TBL_MODELS)
    If Not lo.DataBodyRange Is Nothing Then
        cM = DashColIndex(lo, "Model")
        cR = DashColIndex(lo, "Rows")
        cC = DashColIndex(lo, "Cols")
        cI = DashColIndex(lo, "ImageShapeName")
        dat = lo.DataBodyRange.Value2
        For i = 1 To UBound(dat, 1)
            nm = Trim$(CStr(dat(i, cM)))
            If Len(nm) > 0 And IsNumeric(dat(i, cR)) And IsNumeric(dat(i, cC)) Then
                If CLng(dat(i, cR)) >= 1 And CLng(dat(i, cC)) >= 1 And Not d.Exists(nm) Then
                    d.Add nm, Array(CLng(dat(i, cR)), CLng(dat(i, cC)), Trim$(CStr(dat(i, cI))))
                End If
            End If
        Next i
    End If
    Set HmReadModels = d
End Function

'grp("Model|DefectType") = mang 3x3: (hang thu, 1 = so loi / 2 = hang Grid / 3 = cot Grid)
Private Sub HmBuildTop3(ByVal mdl As Object, ByRef grp As Object, ByRef nSkip As Long)
    Dim k As Variant, p() As String, rc() As String, gk As String
    Dim r As Long, c As Long, v As Double, info As Variant
    Dim t As Variant, blank(1 To 3, 1 To 3) As Double
    Set grp = NewDict()
    nSkip = 0
    For Each k In rHeat.Keys
        p = Split(CStr(k), "|")
        If UBound(p) = 2 Then
            If mdl.Exists(p(0)) Then
                rc = Split(p(2), ",")
                r = CLng(rc(0)): c = CLng(rc(1))
                info = mdl(p(0))
                If r < 1 Or r > CLng(info(0)) Or c < 1 Or c > CLng(info(1)) Then
                    nSkip = nSkip + 1
                Else
                    v = CDbl(rHeat(k))
                    gk = p(0) & "|" & p(1)
                    If grp.Exists(gk) Then
                        t = grp(gk)
                    Else
                        Erase blank
                        t = blank
                    End If
                    HmInsertTop3 t, v, r, c
                    grp(gk) = t
                End If
            End If
        End If
    Next k
End Sub

Private Sub HmInsertTop3(ByRef t As Variant, ByVal v As Double, ByVal r As Long, ByVal c As Long)
    Dim p As Long, q As Long
    For p = 1 To 3
        If v > t(p, 1) Then
            For q = 3 To p + 1 Step -1
                t(q, 1) = t(q - 1, 1): t(q, 2) = t(q - 1, 2): t(q, 3) = t(q - 1, 3)
            Next q
            t(p, 1) = v: t(p, 2) = r: t(p, 3) = c
            Exit Sub
        End If
    Next p
End Sub

'Uu tien hinh that; hinh tam (AutoShape) chi dung khi chua co hinh that
Private Function HmFindImage(ByVal wm As Worksheet, ByVal nm As String) As Shape
    Dim s As Shape, temp As Shape
    For Each s In wm.Shapes
        If StrComp(s.Name, nm, vbTextCompare) = 0 Then
            If s.Type = msoAutoShape Then
                If temp Is Nothing Then Set temp = s
            Else
                Set HmFindImage = s
                Exit Function
            End If
        End If
    Next s
    Set HmFindImage = temp
End Function

'Copy hinh Master cua Model vao Dashboard (tam bat hien thi neu dang an, roi tra lai nhu cu).
'Chi copy lai khi force = True (nut REFRESH) hoac chua co hinh.
Private Function HmModelPicture(ByVal ws As Worksheet, ByVal model As String, ByVal imgName As String, _
                                ByVal force As Boolean) As Shape
    Dim nm As String, s As Shape, src As Shape, wm As Worksheet, wasVis As Boolean
    Dim tries As Long, ok As Boolean
    nm = "HM_PIC_" & model
    Set s = HmFindShape(ws, nm)
    If Not s Is Nothing Then
        If Not force Then
            Set HmModelPicture = s
            Exit Function
        End If
        s.Delete
        Set s = Nothing
    End If
    If Len(imgName) = 0 Then Exit Function
    Set wm = DashSheet(SH_MAP)
    Set src = HmFindImage(wm, imgName)
    If src Is Nothing Then Exit Function

    wasVis = (src.Visible = msoTrue)
    If Not wasVis Then src.Visible = msoTrue
    For tries = 1 To 3
        On Error Resume Next
        Err.Clear
        src.Copy
        If Err.Number = 0 Then ws.Paste Destination:=ws.Range("A" & ROW_HM_FIRST)
        ok = (Err.Number = 0)
        On Error GoTo 0
        If ok Then Exit For
        DoEvents
    Next tries
    On Error Resume Next
    If Not wasVis Then src.Visible = msoFalse
    On Error GoTo 0
    If Not ok Then Exit Function

    Set s = ws.Shapes(ws.Shapes.Count)
    s.Name = nm
    s.Placement = xlMove
    Set HmModelPicture = s
End Function

'Xoa o Top 3 / duong Grid / tieu de / chu giai (giu hinh nen da copy)
Private Sub HmClearShapes(ByVal ws As Worksheet)
    Dim i As Long, nm As String, p As String
    For i = ws.Shapes.Count To 1 Step -1
        nm = ws.Shapes(i).Name
        p = Left$(nm, 5)
        If p = "HM_C_" Or p = "HM_G_" Or p = "HM_T_" Or p = "HM_L_" Then ws.Shapes(i).Delete
    Next i
End Sub

'Xoa hinh nen cua Model khong con hien thi

        nm = ws.Shapes(i).Name
        If Left$(nm, 7) = "HM_PIC_" Then

        End If
    Next i
End Sub

Private Function HmDrawLegend(ByVal ws As Worksheet, ByRef defs() As String, ByVal nD As Long, _
                              ByVal availW As Double) As Double
    Dim i As Long, x As Double, y As Double, w As Double, x0 As Double, y0 As Double
    Dim clr As Long, s As Shape
    x0 = ws.Range("A1").Left + 2
    y0 = ws.Rows(ROW_HM_FIRST).Top + 2
    x = x0: y = y0
    For i = 1 To nD
        w = Len(defs(i)) * 5.6 + 18
        If w < 44 Then w = 44
        If x + w > x0 + availW And x > x0 Then
            x = x0
            y = y + 18
        End If
        clr = DefectColor(defs(i))
        Set s = ws.Shapes.AddShape(msoShapeRoundedRectangle, x, y, w, 15)
        With s
            .Name = "HM_L_" & i
            .Fill.ForeColor.RGB = clr
            .Line.Visible = msoFalse
            .Placement = xlMove
            With .TextFrame2
                .MarginLeft = 2: .MarginRight = 2: .MarginTop = 0: .MarginBottom = 0
                .VerticalAnchor = msoAnchorMiddle
                .WordWrap = msoFalse
                .TextRange.Text = defs(i)
                .TextRange.Font.Size = 8
                .TextRange.Font.Bold = msoTrue
                .TextRange.Font.Fill.ForeColor.RGB = HmTextColor(clr)
                .TextRange.ParagraphFormat.Alignment = msoAlignCenter
            End With
        End With
        x = x + w + 6
    Next i

Private Sub HmStyleCell(ByVal s As Shape, ByVal nm As String, ByVal rank As Long, _
                        ByVal clr As Long, ByVal tip As String)
    Dim fs As Double
    With s
        .Name = nm
        .Fill.ForeColor.RGB = clr
        If rank = 1 Then
            .Fill.Transparency = 0.2
            .Line.Weight = 2
        ElseIf rank = 2 Then
            .Fill.Transparency = 0.4
            .Line.Weight = 1.25
        Else
            .Fill.Transparency = 0.55
            .Line.Weight = 1.25
        End If
        .Line.ForeColor.RGB = clr
        .Placement = xlMove
        .AlternativeText = tip
        fs = HmMax(HmMin(.Height * 0.6, 10), 6)
        With .TextFrame2
            .MarginLeft = 0: .MarginRight = 0: .MarginTop = 0: .MarginBottom = 0
            .VerticalAnchor = msoAnchorMiddle
            .WordWrap = msoFalse
            With .TextRange
                .Text = CStr(rank)
                .Font.Size = fs
                .Font.Bold = msoTrue
                If rank = 1 Then
                    .Font.Fill.ForeColor.RGB = HmTextColor(clr)
                Else
                    .Font.Fill.ForeColor.RGB = RGB(20, 20, 20)
                End If
                .ParagraphFormat.Alignment = msoAlignCenter
            End With
        End With
    End With
    On Error Resume Next
    s.Parent.Hyperlinks.Add Anchor:=s, Address:="", SubAddress:="'" & s.Parent.Name & "'!A1", ScreenTip:=tip
    On Error GoTo 0
End Sub

Private Function HmMin(ByVal a As Double, ByVal b As Double) As Double
    If a < b Then HmMin = a Else HmMin = b
End Function

Private Function HmTextColor(ByVal clr As Long) As Long
    Dim lum As Double
    lum = 0.299 * (clr And 255) + 0.587 * ((clr \ 256) And 255) + 0.114 * ((clr \ 65536) And 255)
    If lum > 150 Then HmTextColor = RGB(0, 0, 0) Else HmTextColor = RGB(255, 255, 255)
End Function

        If veh > 0 Then rate = dft / veh Else rate = 0
        arr(i + 1, 1) = Format$(CDate(dts(i)), "dd/mm")

    s3.Name = "Ti le loi / xe"

    s3.Values = calc.Range(calc.Cells(2, C0 + 3), calc.Cells(n + 1, C0 + 3))
    s3.ChartType = xlLineMarkers
    s3.AxisGroup = xlSecondary
    s3.Format.Line.ForeColor.RGB = RGB(255, 140, 0)
    s3.Format.Line.Weight = 2.25
    s3.MarkerStyle = xlMarkerStyleCircle
    s3.MarkerSize = 6
    s3.MarkerBackgroundColor = RGB(255, 140, 0)
    s3.MarkerForegroundColor = RGB(255, 140, 0)
    s3.HasDataLabels = True
    For i = 1 To n
        dft = arr(i + 1, 2): veh = CLng(arr(i + 1, 3)): rate = arr(i + 1, 4)

Private Function PaintRGB(ByVal colorName As String) As Long
    Dim lo As ListObject, i As Long, dat As Variant, h As String
    PaintRGB = RGB(166, 166, 166)
    On Error GoTo Done
    Set lo = DashTable(SH_MASTER, TBL_COLORS)
    If lo.DataBodyRange Is Nothing Then Exit Function
    dat = lo.DataBodyRange.Value2
    For i = 1 To UBound(dat, 1)
        If StrComp(Trim$(CStr(dat(i, 1))), colorName, vbTextCompare) = 0 Then
            h = Replace(Trim$(CStr(dat(i, 2))), "#", "")
            If Len(h) = 6 Then
                PaintRGB = RGB(CLng("&H" & Mid$(h, 1, 2)), CLng("&H" & Mid$(h, 3, 2)), CLng("&H" & Mid$(h, 5, 2)))
            End If
            Exit Function
        End If
    Next i
Done:
End Function

' LICH CHON NGAY CHO BO LOC From date / To date (Shape tren sheet, KHONG dung UserForm)
' Bam vao o From (A5) hoac To (C5) -> hien lich; chon ngay -> ghi vao o va Dashboard tu cap nhat.
' Su kien Worksheet_SelectionChange / Worksheet_Deactivate cua sheet Dashboard goi DashCalOnSelection / DashCalHide.
'=====================================================================
Public Sub DashCalOnSelection(ByVal Target As Range)
    Dim ws As Worksheet
    On Error Resume Next
    Set ws = Target.Worksheet
    If Target.Cells.Count > 2 Then
        DashCalHide ws
        Exit Sub
    End If
    If Not Intersect(Target, ws.Range(F_FROM).MergeArea) Is Nothing Then
        DashCalShow ws, F_FROM
    ElseIf Not Intersect(Target, ws.Range(F_TO).MergeArea) Is Nothing Then
        DashCalShow ws, F_TO
    Else
        DashCalHide ws
    End If
End Sub

Public Sub DashCalHide(ByVal ws As Worksheet)
    Dim s As Shape
    On Error Resume Next
    If Not DashCalShapeExists(ws, "CAL_BG") Then Exit Sub
    If ws.Shapes("CAL_BG").Visible = msoFalse Then Exit Sub
    For Each s In ws.Shapes
        If Left$(s.Name, 4) = "CAL_" Then s.Visible = msoFalse
    Next s
End Sub

Private Function DashCalShapeExists(ByVal ws As Worksheet, ByVal nm As String) As Boolean
    Dim s As Shape
    On Error Resume Next
    Set s = ws.Shapes(nm)
    DashCalShapeExists = Not s Is Nothing
End Function

Private Sub DashCalShow(ByVal ws As Worksheet, ByVal addr As String)
    Dim v As Variant, L As Single, T As Single, i As Long, prevSU As Boolean
    prevSU = Application.ScreenUpdating
    Application.ScreenUpdating = False
    mDcTarget = addr
    v = ws.Range(addr).Value
    If IsDate(v) Then
        mDcYear = Year(CDate(v)): mDcMonth = Month(CDate(v))
    Else
        mDcYear = Year(Date): mDcMonth = Month(Date)
    End If
    DashCalBuild ws
    L = ws.Range(addr).Left
    T = ws.Rows(7).Top                                  'ngay duoi vung freeze (hang 1-6)
    On Error Resume Next
    T = ActiveWindow.Panes(2).VisibleRange.Top
    On Error GoTo 0
    DashCalLayout ws, L, T
    ws.Shapes("CAL_BG").Visible = msoTrue
    ws.Shapes("CAL_TITLE").Visible = msoTrue
    ws.Shapes("CAL_PREV").Visible = msoTrue
    ws.Shapes("CAL_NEXT").Visible = msoTrue
    ws.Shapes("CAL_TODAY").Visible = msoTrue
    For i = 1 To 7
        ws.Shapes("CAL_W" & i).Visible = msoTrue
    Next i
    DashCalDraw ws
    Application.ScreenUpdating = prevSU
End Sub

Private Function DashCalBox(ByVal ws As Worksheet, ByVal nm As String, ByVal txt As String, _
                            ByVal fillClr As Long, ByVal fontClr As Long, ByVal sz As Single, _
                            ByVal isBold As Boolean, ByVal macroName As String) As Shape
    Dim s As Shape
    Set s = ws.Shapes.AddShape(msoShapeRectangle, 0, 0, 26, 20)
    With s
        .Name = nm

        .Line.Visible = msoFalse

        With .TextFrame2
            .MarginLeft = 0: .MarginRight = 0: .MarginTop = 0: .MarginBottom = 0

                .Font.Fill.ForeColor.RGB = fontClr

    Set DashCalBox = s

Private Sub DashCalBuild(ByVal ws As Worksheet)
    Dim s As Shape, i As Long, heads As Variant
    If DashCalShapeExists(ws, "CAL_BG") Then Exit Sub
    heads = Array("T2", "T3", "T4", "T5", "T6", "T7", "CN")
    Set s = DashCalBox(ws, "CAL_BG", "", RGB(255, 255, 255), RGB(0, 0, 0), 9, False, "DashCalNoop")
    s.Line.Visible = msoTrue
    s.Line.ForeColor.RGB = RGB(31, 56, 100)
    s.Line.Weight = 1.5
    DashCalBox ws, "CAL_PREV", "<", RGB(31, 78, 121), RGB(255, 255, 255), 11, True, "DashCalPrev"
    DashCalBox ws, "CAL_NEXT", ">", RGB(31, 78, 121), RGB(255, 255, 255), 11, True, "DashCalNext"
    DashCalBox ws, "CAL_TITLE", "", RGB(255, 255, 255), RGB(16, 37, 66), 11, True, "DashCalNoop"
    For i = 1 To 7
        DashCalBox ws, "CAL_W" & i, CStr(heads(i - 1)), RGB(242, 244, 247), IIf(i = 7, RGB(192, 0, 0), RGB(64, 64, 64)), 9, True, "DashCalNoop"
    Next i
    For i = 1 To 42
        DashCalBox ws, "CAL_D" & i, "", RGB(255, 255, 255), RGB(0, 0, 0), 10, False, "DashCalPick"
    Next i
    DashCalBox ws, "CAL_TODAY", "Hom nay", RGB(255, 242, 204), RGB(16, 37, 66), 10, True, "DashCalToday"
End Sub

Private Sub DashCalLayout(ByVal ws As Worksheet, ByVal L As Single, ByVal T As Single)
    Dim i As Long, totalW As Single
    Const CW As Single = 26
    Const CH As Single = 20
    totalW = 7 * CW + 10
    With ws.Shapes("CAL_BG")
        .Left = L: .Top = T: .Width = totalW: .Height = 196
    End With
    With ws.Shapes("CAL_PREV")
        .Left = L + 5: .Top = T + 4: .Width = CW: .Height = 20
    End With
    With ws.Shapes("CAL_NEXT")
        .Left = L + 5 + 6 * CW: .Top = T + 4: .Width = CW: .Height = 20
    End With
    With ws.Shapes("CAL_TITLE")
        .Left = L + 5 + CW: .Top = T + 4: .Width = 5 * CW: .Height = 20
    End With
    For i = 1 To 7
        With ws.Shapes("CAL_W" & i)
            .Left = L + 5 + (i - 1) * CW: .Top = T + 26: .Width = CW: .Height = 16
        End With
    Next i
    For i = 1 To 42
        With ws.Shapes("CAL_D" & i)
            .Left = L + 5 + ((i - 1) Mod 7) * CW
            .Top = T + 44 + ((i - 1) \ 7) * CH
            .Width = CW: .Height = CH
        End With
    Next i
    With ws.Shapes("CAL_TODAY")
        .Left = L + 5: .Top = T + 44 + 6 * CH + 4: .Width = totalW - 10: .Height = 20
    End With
End Sub

Private Sub DashCalDraw(ByVal ws As Worksheet)
    Dim firstDay As Date, offset As Long, daysIn As Long, i As Long, d As Long
    Dim dd As Date, sel As Date, s As Shape, v As Variant
    firstDay = DateSerial(mDcYear, mDcMonth, 1)
    offset = Weekday(firstDay, vbMonday) - 1
    daysIn = Day(DateSerial(mDcYear, mDcMonth + 1, 0))
    ws.Shapes("CAL_TITLE").TextFrame2.TextRange.Text = "Thang " & mDcMonth & "/" & mDcYear
    v = ws.Range(mDcTarget).Value
    If IsDate(v) Then sel = CDate(v) Else sel = 0
    For i = 1 To 42
        d = i - offset
        Set s = ws.Shapes("CAL_D" & i)
        If d >= 1 And d <= daysIn Then
            dd = DateSerial(mDcYear, mDcMonth, d)
            s.TextFrame2.TextRange.Text = CStr(d)
            s.Fill.ForeColor.RGB = RGB(255, 255, 255)
            s.TextFrame2.TextRange.Font.Fill.ForeColor.RGB = IIf(((i - 1) Mod 7) = 6, RGB(192, 0, 0), RGB(0, 0, 0))
            If dd = Date Then s.Fill.ForeColor.RGB = RGB(255, 230, 153)
            If sel <> 0 And dd = sel Then
                s.Fill.ForeColor.RGB = RGB(31, 78, 121)
                s.TextFrame2.TextRange.Font.Fill.ForeColor.RGB = RGB(255, 255, 255)
            End If
            s.Visible = msoTrue
        Else
            s.Visible = msoFalse
        End If
    Next i
End Sub
